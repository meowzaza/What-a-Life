## 1. แก่นของเกม (Core Pillars)
1. **ชีวิตจริงยิ่งกว่านิยายในบริบทไทยร่วมสมัย:** จำลองชีวิตตั้งแต่เกิดจนตาย (และส่งต่อทายาท) ท่ามกลางระบบการศึกษาไทย (กศน./TCAS), เส้นทางอาชีพและธุรกิจส่วนตัว, ค่านิยมครอบครัว, หน้าตาทางสังคม, และจุดพลิกผัน (Twist) ที่มีลางบอกเหตุรองรับ
2. **ตารางแผนชีวิต + การลงมือทำเอง (Planner Grid + Active Sandbox):**
   - เบื้องหลังขับเคลื่อนด้วย **กริดตารางแผนชีวิตประจำสัปดาห์ (เช้า/บ่าย/เย็น/ดึก × วันธรรมดา/วันหยุด)** ที่คำนวณออกมาเป็น 168 ชม./สัปดาห์อัตโนมัติ
   - เบื้องหน้าผู้เล่นสามารถกดสั่งทำกิจกรรมพิเศษรายวัน (คิวคำสั่งแทรกตาราง), สมัครเรียน/สมัครงาน, ปั้นโปรเจกต์/ธุรกิจ, เปลี่ยนลุค และปฏิสัมพันธ์กับผู้คนได้เองตลอดเวลา
3. **ทุกการกระทำทิ้งหลักฐานและผลสะท้อน (Evidence -> Trait -> Storylet -> Echo):**
   - กิจวัตรและการตัดสินใจสะสมเป็น `Evidence` -> งอกหรือจางเป็นนิสัย `Trait` 3 ชั้น -> ดึงดูดเหตุการณ์และปลดล็อกทางเลือกเฉพาะตัว -> ส่งผลสะท้อนหน่วงเวลาผ่าน `Echo Queue` พร้อมปุ่ม **"ทำไม?" (`explain()`)** ที่อธิบายสาเหตุย้อนหลังได้ทุกเหตุการณ์

## 2. กฎวิศวกรรมและระบบหลัก (Architectural Invariants)
- **โครงสร้าง 3 ชั้นแยกขาดจากกัน:**
  - `src/engine/*` — Pure TypeScript functions รับ `(state, action)` คืนค่า `GameState` ใหม่พร้อม `rngState` ที่ขยับแล้ว (Deterministic 100%, ไม่มี Side Effect)
  - `src/data/*` — ตารางค่าคงที่, คลัง Storylet, ข้อมูลอาชีพ/การศึกษา, และข้อความภาษาไทย (`uiText.ts`)
  - `src/ui/*` — React components แสดงผลตาม `GameState` เท่านั้น (ธีม Soft Pastel Pixel, รองรับจอมือถือ `360–400 px`, แถบควบคุมเวลาติดขอบจอไม่เลื่อนหาย, การ์ดตัดสินใจใช้แม่แบบเดียวทั้งเกม)
- **ระบบเวลาและระดับเหตุการณ์:**
  - `1 Tick = 1 วัน` มี 4 ช่วงเวลา (`morning`, `afternoon`, `evening`, `night`) และตัวคูณความเร็ว `Pause / x1 / x2 / x5 / x20`
  - เหตุการณ์ 4 ระดับ: **T0** (บรรยากาศในฟีด), **T1** (แถบแจ้งเตือนสั้นๆ), **T2** (การ์ดทางเลือก 2–4 ข้อ มีเวลานับถอยหลัง), **T3** (จุดเปลี่ยนชีวิต บังคับลดความเร็วเป็น `x1` และ **ไม่มีเวลานับถอยหลัง**)
- **กฎเหล็กด้านความปลอดภัยผู้เยาว์ (`src/data/lifeStages.ts`):**
  - **ตารางกติกาอายุ-งาน-เงินฉบับเต็มอยู่ที่สเปก `03` §1 (แหล่งเดียว)** `[อัปเดต · 3.3.3]` สรุปสั้น: อายุ `< 13` ค้นพบ/เรียนทักษะได้แต่ยังไม่มีรายได้; `13–14` ทำได้เฉพาะ "งานความสามารถ" (เปิดหมวกร้องเพลง, แข่งเต้นงานตลาด, ประกวดวาดรูป, ขายของกับผู้ปกครอง) ต้องมีผู้ปกครองดูแลและเพดานรายได้ต่อเดือน; `15–17` ทำเองได้รวมขายของออนไลน์; **ห้ามแรงงานทุกกรณีก่อนอายุ 15** (พาร์ตไทม์/โอที/กะดึก/งานในสถานบันเทิง) และห้ามโอที/กะดึกจนอายุ 18
  - รายจ่ายครองชีพ `< 15` ปี = `0` แต่ **ใช้เงินติดตัวซื้อขนม/อุปกรณ์/คอร์สได้** (ไม่มีรายจ่ายครองชีพ ≠ ห้ามใช้เงิน) `[อัปเดต · 3.3.3]`
  - อายุ `< 18` ปี (`isMinor = true`): อยู่บ้านผู้ปกครองฟรี, ห้ามเข้าฉากผับ/สถานบันเทิงกลางคืน, ห้ามทำโอที/กะดึก, และ Storylet ต้องมี `isMinorSafe: true` เท่านั้น (สถานการณ์สุ่มเสี่ยงทั่วไปได้ เช่น ซื้อถุงยาง, แฟนชวนไปบ้านในวันที่ไม่มีใครอยู่บ้าน, ท้องในวัยเรียน, เพื่อนชวนลองสารเสพติด ฯลฯ)

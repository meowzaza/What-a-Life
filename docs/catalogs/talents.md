### กติกาเพิ่มเติม
- **ลางบอก** (`ev_talent_hint` ใน `events.md`): ทุกพรสวรรค์ที่ยังไม่เปิดเผยมีลางบอก 2–3 รูปแบบต่างกัน (ไม่โชว์ตัวเลข)
- **ได้มาระหว่างชีวิต:** พรสวรรค์ไม่ได้มาจากเวลาล้วนๆ มาจาก (ก) กาชา (ข) เหตุการณ์ใหญ่หายาก (ค) อัจฉริยะเจอเอง ตามเงื่อนไข; ข้อจำกัดอาจเกิดเพิ่มระหว่างชีวิตตามเหตุการณ์/นิสัยสะสม
- **lot เก็บพรสวรรค์ ≤ 5** (CORE §9–10) นับรวมที่เกิดมา + กาชา; เกิน 5 ต้องเลือกทิ้ง 1 (ทิ้งแล้วเรียกคืนไม่ได้) ดูช่องใช้งาน 3 ช่อง ที่สเปก 07 §1.4
- **เพดานกลางกันทับซ้อน:** ผลจากพรสวรรค์ + ของขลัง + ฉายา รวมกันต้องไม่เกินเพดานกลาง (ค่าเพดานตัดสินใน 3.3.1)
- **กาชาพรสวรรค์ (3.3.3):** ราคาเริ่ม 3,000 ฿ + ค่าอื่น (เวลา/เหรียญกิจกรรม) การันตีพรสวรรค์ใดสักอย่างภายใน 10 ครั้ง; ความแรงสุ่ม เล็ก 70% / กลาง 25% / ใหญ่ 5% ; ห้ามผู้เยาว์ใช้เงินเกินเพดานต่ำ (CORE §9)
- **ช่องพรสวรรค์ `[ใหม่ · 3.3.1-FIX]`:** ใช้งานพร้อมกัน **3 ช่อง** ส่วนเกินเข้า lot (≤ 5) · ค้นพบระหว่างชีวิตห่างกัน ≥ 3 ปีเกม ไม่เกิน 1 ครั้งต่อช่วงชีวิต · สลับช่องใช้งาน↔lot ได้เฉพาะจุดเปลี่ยน (ปีใหม่/เปิดเทอม/ย้ายงาน/หลังเหตุการณ์ T3) · พรสวรรค์ใน lot ไม่ให้ผล · ข้อจำกัดไม่กินช่อง สลับออกไม่ได้ ต้องแก้ตามช่องทาง (รายละเอียด สเปก 07 §1.4)
- **ตัวคูณความเร็วฝึก `[อัปเดต · 3.3.1-FIX]`:** เล็ก/กลาง/ใหญ่ = +10/20/30% (ปรับจาก +15/30/50% ในคอลัมน์ผลของแถวด้านบนให้ตรงเพดานกลาง +40% ตามสเปก 05 §3) ให้แก้ตัวเลข +15/30/50% ในทุกแถวเป็น +10/20/30%

## กติกาทางเลือกการเรียน (แทรกจากแชท: ซิ่ว ย้ายสาขา ลาออก ทุน) `[อัปเดต · 3.3.2]`

### 1. คะแนนคัดเลือกแบบถ่วงน้ำหนัก (ไม่ใช่เกณฑ์ขั้นต่ำเด็ดขาด)
`คะแนนสมัคร = (ทักษะตรงสาย x น้ำหนักสาย) + (GPA x น้ำหนัก) + (tcasExamScore x น้ำหนัก, รอบ A) + โบนัสพอร์ต/ฉายา/สภา/ชมรม + ผลสัมภาษณ์` แล้วเทียบกับ `คะแนนตัด = f(prestige, competition, จำนวนที่นั่งสาขา)`
- ค่า `prestige` สูง → ตัวเลขฉายา/พอร์ตมีน้ำหนักมากขึ้นตอนสัมภาษณ์ และจบแล้วได้โบนัสสมัครงาน
- ค่า `competition` สูง → คะแนนตัดสูง ที่นั่งน้อย โอกาสติดต่ำแม้ผ่านเกณฑ์ทักษะ
- ผ่านเกณฑ์ทักษะแต่ไม่ถึงคะแนนตัด = "ติดสำรอง/ไม่ติด" ไม่ใช่ตัดทิ้ง; ต่ำกว่าเกณฑ์ทักษะมากอาจสมัครได้แต่โอกาสต่ำมาก
- ค่าเทอม **ไม่ผูก** กับ prestige (ที่ถูกแต่ดังก็มี ที่แพงแต่ไม่ดังก็มี)

### 2. ทางเลือกหลังเข้าเรียน (ทุกข้อเป็นเหตุการณ์ตัวเลือก ≥4 + ตัวเลือกพิเศษ ตาม CORE §6.1)

### 4. เรียนพิเศษ/ติวเข้มก่อนสอบ (อ้างสเปก `05` เป็นแหล่งเดียว ไม่เขียนซ้ำ)
คอร์สติวสอบกลาง/ติวพอร์ต/ติวสัมภาษณ์/ติวภาษา ใช้ช่องตารางหมวด `self_dev` ตามสเปก 05 · ผลคือตัวคูณเรียนรู้ทักษะตรงสายและโบนัสรอบ A/P ตามที่สเปก 05 กำหนด · กรณีพรสวรรค์ `lim_slow_learner` ติวเตอร์ช่วยแก้ข้อจำกัดได้ (ดู `talents.md`)

### 5. สัมภาษณ์แบบสุ่มตามสาย (ตาราง `สัมภาษณ์%` ด้านบนเป็นค่าตั้งต้น)
- รอบ P (พอร์ต): สอบปฏิบัติ/สัมภาษณ์ 1–2 ข้อ ทุกสาย "ศิลปะ/ดนตรี/การแสดง/กีฬา/อาหาร" บังคับ 100%
- รอบ Q/A: โอกาสสัมภาษณ์ตามคอลัมน์ `สัมภาษณ์%` ของสาขา (แพทย์/นักบิน/ความมั่นคง 100%)
- ผลสัมภาษณ์ = ตรวจทักษะ/ฉายา/บุคลิก (พรสวรรค์เจรจา/เสน่ห์ช่วยได้) → ผ่านเด่น/ผ่าน/สำรอง/ไม่ผ่าน ทุกตัวเลือกมีผลพลาดที่ยังเล่นต่อได้

# งานพาร์ตไทม์ ผับ/ตลาดกลางคืน และระบบช่วงเวลาของวัน (Daypart)

เกม ชีวิตจริงยิ่งกว่านิยาย · เอกสารสเปกสำหรับ Engine และ AI · ฉบับที่ 1

ใช้คู่กับ `01_scene_catalog_v2.md` (ฉาก) และ `02_housing_system.md` (ค่าที่อยู่) หลักการเดิม: Engine ตัดสินตัวเลข AI เล่าเรื่อง

## 0. ตัวเลขอ้างอิงตั้งต้น (ปี 2569)

- ค่าจ้างขั้นต่ำ: กรุงเทพฯ 400 บาท/วัน, จังหวัดอื่นราว 337-399 (ค่ากลางราว 355-370), ชนบทต่ำสุดราว 337-354 บาท/วัน ค่าตั้งต้นของเกม `minWagePerDay`: กทม. 400 / หัวเมืองใหญ่ 380 / จังหวัดทั่วไป 360 / ชนบท 345
- กิจการสถานบริการ (ผับ บาร์ คาราโอเกะ ค็อกเทลเลานจ์) ค่าจ้างขั้นต่ำ 400 บาท/วันทั่วประเทศ
- ค่าจ้างรายชั่วโมงพาร์ตไทม์ = ค่าจ้างขั้นต่ำรายวัน / 8 เป็นพื้นขั้นต่ำ (กทม. ≈ 50 บาท/ชม.) งานจริงมักสูงกว่าเล็กน้อย
- ทุกตัวเลขเป็นค่าตั้งต้น ปรับผ่านซิมหมื่นชีวิต ไม่ฝังในโค้ด

## 1. การ์ดงาน (Job Card) ที่ Engine ต้องมี

```ts
interface Job {
  id: string;
  nameTh: string;
  sceneId: string;              // ฉากที่ใช้แสดงตอนทำงาน
  minAge: number;
  maxAgeHint?: number;
  dayparts: ('morning'|'afternoon'|'evening'|'night')[]; // ช่วงเวลาที่ทำได้
  pay: { type: 'hourly'|'daily'|'monthly'|'perOrder'|'perNight'|'commission'; low: number; typical: number; high: number };
  tipsPerShift?: [number, number];
  costs?: { perShift?: number; upfront?: number; description: string }[];
  requires: string[];           // เช่น 'license_motorbike', 'bike', 'phone', 'skill:music>=30'
  skillGain: Record<string, number>;
  riskTags: string[];           // ใช้เลือกเหตุการณ์ เช่น 'accident','harassment','police_raid'
  legal: { entertainmentVenue?: boolean; night?: boolean };
}
```

AI ห้ามสร้างงานใหม่ที่ไม่ลงทะเบียน ถ้าเสนองานใหม่ให้ผ่าน Validator เข้าคลังก่อน

## 2. กฎอายุและเวลาทำงาน (ตั้งค่าได้ใน "ความสมจริง")

| อายุ | ทำอะไรได้ |
| --- | --- |
| < 15 | ไม่มีงานจ้าง (ช่วยงานครอบครัวเท่านั้น) |
| 15-17 | งานเบาพาร์ตไทม์เฉพาะนอกเวลาเรียน (ร้านกาแฟ ร้านอาหาร มินิมาร์ทช่วงกลางวัน-เย็น) ไม่เกิน 8 ชม./วัน ห้ามทำงานช่วง 22:00-06:00 ห้ามงานในสถานบริการ/ผับ ห้ามงานเสี่ยงอันตราย |
| 18+ | งานทั่วไปทุกประเภท รวมไรเดอร์ (ต้องมีใบขับขี่) งานกะดึก และงานในผับ/บาร์ (ตำแหน่งพนักงาน) |
| 20+ (ค่าตั้งต้น) | **เข้าไปใช้บริการ/ดื่มในผับ** ตามกฎหมายไทย (ตัวเลือกในตั้งค่าลดเป็น 18 ได้) |

กฎผู้เยาว์ใน Engine คงเดิม: ต่ำกว่า 18 ล็อกเนื้อหาผู้ใหญ่ถาวร ไม่ผ่าน AI

## 3. ระบบช่วงเวลาของวัน (Daypart)

เกมใช้ 1 tick = 1 วัน ไม่มีนาฬิกาในวัน จึงใช้ `daypart` เป็นตัวกำหนด "ฉากกลางวัน/กลางคืน" "ร้านเปิดหรือยัง" และกะงาน

| daypart | ช่วงเวลา | ภาพที่ใช้ |
| --- | --- | --- |
| `morning` | 05:00-11:59 | day |
| `afternoon` | 12:00-16:59 | day |
| `evening` | 17:00-20:59 | night (ไฟเริ่มติด) ถ้าฉากไม่มีภาพกลางคืนใช้ day |
| `night` | 21:00-04:59 | night |

### เลือก daypart ปัจจุบัน (ฟังก์ชันล้วน resolveDaypart จากสถานะ ได้ผลเหมือนเดิมเมื่อ seed เท่ากัน)

ลำดับความสำคัญ (ข้อบนชนะ):

1. เหตุการณ์/Scene Mode ระบุ daypart เอง
2. งานที่ทำอยู่ตอนนี้: กะของงานนั้น (เช่น บาร์เทนเดอร์ = night, ไรเดอร์ตามกะที่ตั้งไว้)
3. กิจวัตรหลักของสัปดาห์: ถ้าตารางเวลา (Time Allocation) มีสัดส่วนช่วงกลางคืน (nightlife/ปาร์ตี้/นอนดึก) มากที่สุด = night
4. ค่าเริ่มต้น: morning/afternoon สลับตามวันในสัปดาห์

### ฉากที่ถูกจำกัดตามเวลา (Availability Gate)

| ฉาก | เปิด | daypart ที่เรียกได้ | ถ้าไม่เปิด |
| --- | --- | --- | --- |
| `street_food_night` ซอยอาหารกลางคืน | 18:00-03:00 | evening, night | **ไม่ถูกเรียกเลย** ไม่มีปุ่มให้ไป |
| `nightlife_pub` ผับ | 18:00-02:00 | evening (หลัง 18:00), night | **ไม่ถูกเรียกเลย** (ยังไม่เปิด) |
| `cafe` | 07:00-21:00 (ส่วนมาก) | morning, afternoon, evening | ภาพกลางคืนแสดงเมื่อเปิดดึก |
| `shop_minimart` | 24 ชม. | ทุกช่วง | - |
| `restaurant_tamsang` | 06:00-22:00 | morning-evening | ปิดดึก |
| `market_fresh` | 04:00-21:00 | morning-evening | ปิดดึก |
| `street_shops` | ถนนเดินได้ 24 ชม. ร้านเปิด 07:00-22:00 | ทุกช่วง (ร้านปิดตอนดึก) | - |
| `hospital` | 24 ชม. (ฉุกเฉิน) | ทุกช่วง | - |
| `school_*` | 07:00-17:00 | morning, afternoon | ภาพกลางคืน = กิจกรรมพิเศษ/ค่าย |
| `university` | 07:00-22:00 | ทุกช่วง (ห้องสมุดดึก) | - |
| `work_corporate` | 08:00-18:00 | morning, afternoon (OT = evening/night) | - |
| `work_warehouse` | 24 ชม. เป็นกะ | ทุกช่วง | - |

Engine: ฟังก์ชัน `isSceneOpen(sceneId, daypart, age, settings)` คืน true/false ถ้า false ห้ามนำฉากนั้นไปแสดง ห้ามให้ปุ่ม "ไปที่นั่น" โผล่ และ Storylet ที่ระบุฉากนั้นต้องรอ daypart ที่ตรง

UI: ปุ่ม "ช่วงเวลาที่จะออกไปข้างนอก" (ตอนเช้า/บ่าย/เย็น/กลางคืน) ปุ่มกลางคืนเปิดใช้ได้เมื่อตัวละครอายุ ≥ 18 หรือมีเหตุผล (กะดึก) ผู้เล่นเลือกไปซอยอาหารกลางคืนได้เฉพาะเมื่อเลือก evening/night

## 4. ตารางงานตามฉาก

ตัวเลขเป็นระดับกรุงเทพฯ ค่าตั้งต้น ปรับด้วยตัวคูณภูมิภาค (เมืองใหญ่ 0.85 / จังหวัดทั่วไป 0.7 / ชนบท 0.6)

### 4.1 คาเฟ่ (`cafe`)

| งาน | อายุ | daypart | รายได้ | หมายเหตุ |
| --- | --- | --- | --- | --- |
| พนักงานพาร์ตไทม์/บาริสต้า | 15+ (15-17 ต้องเป็นกลางวันเท่านั้น) | morning-evening | 55-80 บาท/ชม. (ชม. ละ 60 ค่ากลาง) ทิป 0-150/กะ | ทักษะ: บริการ ชงกาแฟ |
| บาริสต้าประจำ | 18+ | กะเช้า/เย็น | 12,000-20,000 บาท/เดือน | ปรับเลื่อนเป็นหัวหน้ากะ 18,000-28,000 |
| เจ้าของร้านกาแฟ | 20+ | ทั้งวัน | กำไร 0-60,000/เดือน (เสี่ยงขาดทุน) | ต้องลงทุน 300,000-1,500,000 |

**คาเฟ่ในฐานะ "พื้นที่ที่สาม"** (กิจกรรมที่ผู้เล่นเลือกทำได้ ไม่ต้องเป็นงาน) ค่ากาแฟ 60-130 บาท/ครั้ง

| กิจกรรม | ผล | ต้นทุน |
| --- | --- | --- |
| นั่งทำงาน/นำงานมาทำ | งานฟรีแลนซ์/รีโมตได้ผลดีขึ้น (+โฟกัส -ความเหงา) งานรับจ้างออนไลน์ 200-2,000 บาท/วัน ตามทักษะ | กาแฟ 60-130 + เวลา |
| อ่านหนังสือ/ติว | ทักษะเรียนเพิ่ม | เหมือนกัน |
| พักผ่อน | Stress ลดเล็กน้อย Energy ฟื้น | เหมือนกัน |
| นัดเจอคน (เพื่อน เดต สัมภาษณ์ ประชุมงาน) | ฉากนัดหมายใช้ภาพคาเฟ่ ผลตามนิสัยคู่ | ค่าเครื่องดื่ม 2 คน |
| พบคนใหม่ (Dynamic Opportunity) | โอกาสเจอ NPC ใหม่ คนรู้จักขาประจำ เพื่อน คู่เดต คู่ค้า (สุ่มถ่วงน้ำหนักตามทักษะสังคมและความถี่ที่มา) | - |

เหตุการณ์ตัวอย่าง: บาริสต้าชวนลงทุน, คนข้างโต๊ะลืมกระเป๋าเอกสาร, ได้งานฟรีแลนซ์จากคนข้างโต๊ะ, ถูกไล่เพราะนั่งนานเกินไปไม่สั่งอะไร, เจอแฟนเก่า, ลูกค้าประจำสนิทกัน

### 4.4 ถนนร้านค้า (`street_shops`) และไรเดอร์

ฉากนี้คือย่านร้านรวง (ร้านสะดวกซื้อ ซ่อมมือถือ ร้านกาแฟ) ใช้เป็นฉากเมื่อ: เดินเล่น ไรเดอร์รับของ งานซ่อมมือถือ งานเสริม เหตุการณ์หางานพิเศษ

#### ไรเดอร์ส่งอาหาร/พัสดุ (`rider_delivery`)

| รายการ | ค่าตั้งต้น |
| --- | --- |
| อายุ | 18+ เท่านั้น (ตามเงื่อนไขแพลตฟอร์ม) |
| ต้องมี | ใบขับขี่รถจักรยานยนต์, มอเตอร์ไซค์ (ของตัวเองหรือเช่า 120-250 บาท/วัน), มือถือ, ถุงส่งของ (ลงทุน 500-1,500) |
| รายได้ต่อออเดอร์ | 25-60 บาท (ระยะทาง) + โบนัสช่วงเร่งด่วน/ฝนตก 5-30 บาท |
| ออเดอร์ต่อชั่วโมง | ช่วงเที่ยง/เย็น 2-4 ออเดอร์ ช่วงอื่น 1-2 ออเดอร์ ฝนตกเยอะขึ้นแต่เสี่ยงขึ้น |
| พาร์ตไทม์ 4 ชม. (ช่วงเย็น) | รายรับ 200-450 บาท หักน้ำมัน 30-80 เหลือราว 150-380 |
| เต็มเวลา 10 ชม. | รายรับ 700-1,200 บาท หักน้ำมัน/ซ่อม/ค่าเช่ารถเหลือราว 450-850 |
| ต้นทุนแฝง | น้ำมัน (ผูกราคาน้ำมันในเหตุการณ์เศรษฐกิจ) ค่าซ่อมบำรุง ยางแตก ค่าปรับจราจร ประกันอุบัติเหตุ |
| ความเสี่ยง | อุบัติเหตุ (เสี่ยงตามชั่วโมงขับ ฝน ความเร็ว) ถูกลูกค้ารีวิวแย่ถูกระงับบัญชี ถูกโกง/ถูกยกเลิกกลางทาง รถหาย |
| ทักษะ | ขับขี่ รู้จักเส้นทาง สถานะร่างกายเสื่อมตามชั่วโมงสะสม |

Daypart: ทำงานกะ morning/afternoon/evening ได้ตลอด กะ night มีออเดอร์น้อยแต่ราคาต่อเที่ยวสูง ไม่ใช้ตัวคูณผับ

## 6. ผับ (`nightlife_pub`) กลางคืนเท่านั้น

เปิด 18:00-02:00 เรียกเฉพาะ evening/night เข้าใช้บริการได้ที่อายุ 20+ (ค่าตั้งต้น ปรับเป็น 18 ได้ในตั้งค่า) ผู้เยาว์ไม่มีปุ่มและไม่ถูกเรียก ล็อกใน Engine

### งานในผับ (อายุ 18+ ขึ้นไป ค่าจ้างพื้นฐาน 400 บาท/วันตามกฎสถานบริการ)

| งาน (jobId) | อายุ | รายได้ | หมายเหตุ |
| --- | --- | --- | --- |
| `pub_musician` นักดนตรีในผับ | 18+ | 1,000-3,000/คืน (วงดัง 3,000-10,000) 2-4 คืน/สัปดาห์ | ทักษะดนตรี ≥ 40; ถ้าทำดีติดต่องานเลี้ยง/ค่ายเพลง |
| `pub_bartender` บาร์เทนเดอร์ | 18+ | 12,000-25,000/เดือน + ทิป 500-2,000/คืน (หัวหน้าบาร์ 25,000-45,000) | ทักษะบริการ+ชงเครื่องดื่ม; เจอคนเมา ปัญหาลูกค้า |
| `pub_waiter` เด็กเสิร์ฟ | 18+ | 400-600/วัน + ทิป 200-1,000 | เหนื่อย ยืนนาน ลูกค้าหยาบ |
| `pub_security` รปภ./บาวน์เซอร์ | 20+ | 600-1,200/คืน | ทักษะร่างกาย; ตีกัน ตรวจบัตรอายุ |
| `pub_dj` ดีเจ | 18+ | 1,500-8,000/คืน | ทักษะดนตรี/มีอุปกรณ์ |
| `pub_hostess` พนักงานนั่งดริ้ง (เด็กนั่งดริ้ง) | 18+ | ค่าจ้างพื้นฐาน 400 + ค่าเครื่องดื่มต่อแก้ว 30-150 + ทิป 500-5,000/คืน (ผันผวนสูง) | ดูกติกาด้านล่าง |

### กติกา `pub_hostess` (ค่าตั้งต้น เล่าแบบละคร ไม่โจ่งแจ้ง)

- ล็อก 18+ ใน Engine ถ้าผู้เล่นตั้ง "ผู้เล่นอายุเข้าใช้บริการ = 20" งานนี้เริ่มที่ 20+ ให้สอดคล้องกัน
- เนื้อหาเน้นผลเชิงชีวิต: รายได้ ทิป ค่าเครื่องดื่ม แรงกดดันให้ดื่ม สุขภาพ ความสัมพันธ์ ชื่อเสียงในครอบครัว/ชุมชน การถูกมาม่าซังหักเงินหรือค่าปรับ หนี้สิน ความปลอดภัย ผู้เล่นเลือกปฏิเสธได้เสมอ (ผลต่อรายได้/ชื่อเสียงตามจริง)
- ฉากที่ละเอียดอ่อนใช้การเล่าเป็นข้อความตัดฉาก ไม่บรรยายรายละเอียดทางเพศ
- เหตุการณ์เสี่ยง: ลูกค้าตื๊อ/ล่วงละเมิด (ผู้เล่นตอบโต้/ขอความช่วยเหลือได้), ติดดื่ม, ตำรวจเข้าตรวจ, เสี่ยเลี้ยงเสนอ (ตามระดับเนื้อหาที่ผู้เล่นตั้ง), ถูกทำให้เสียชื่อเสียง, ทางออกจากงาน (เพื่อน ครอบครัว แผนเงินอื่น)
- ผลต่อ Stress สูง แต่ก็เพิ่ม Social ในบางลักษณะนิสัย (Trait Drift: ติดการสังสรรค์ ติดดื่ม)

### กิจกรรมของผู้ใช้บริการในผับ (20+)

| กิจกรรม | ผล | ต้นทุน |
| --- | --- | --- |
| ดื่มกับเพื่อน | Social ขึ้น Stress ลง สุขภาพ/เงินเสี่ยง | 500-3,000/คืน |
| เดต/หาคู่ | โอกาสพบ NPC ใหม่ | 1,000-5,000 |
| นั่งโต๊ะแอลกอฮอล์สูง/ยกขวด | สถานะสังคมขึ้นในวงเพื่อน | 3,000-20,000 |
| เสพติดการดื่ม | Trait ติดสุรา หนี้ ตับ | สะสม |

เหตุการณ์: เมาแล้วทะเลาะ ชู้สาว เจอแฟนเก่า เสี่ยเลี้ยงเสนอ ตำรวจตรวจปัสสาวะ/ตรวจบัตร ถูกวางยา (ผู้เล่นรับมือได้ด้วยความระวัง/เพื่อนช่วย) ติดพนัน

## 7. เหตุการณ์หางานเสริม (Side-Gig Events) เทมเพลต

ใช้ Storylet ที่เรียกเมื่อเงินสดต่ำกว่าเกณฑ์ หรือเป็นเหตุการณ์สุ่มตามฉาก

| เงื่อนไข | เหตุการณ์ | ทางเลือก |
| --- | --- | --- |
| เงินสด < ค่าครองชีพ 1 เดือน, อายุ 18+ | เพื่อนชวนสมัครไรเดอร์ | สมัคร (ลงทุนอุปกรณ์) / ปฏิเสธ / ขอยืมเพื่อน |
| อยู่ที่คาเฟ่ + ทักษะออนไลน์ ≥ 30 | คนข้างโต๊ะจ้างทำงานฟรีแลนซ์ | รับงาน / ต่อรองค่าตอบแทน / ปฏิเสธ |
| ย่านถนนร้านค้า + ทักษะซ่อม ≥ 20 | ร้านซ่อมมือถือเปิดรับช่าง | สมัคร / เรียนเพิ่ม |
| ซอยอาหารกลางคืน + ทักษะดนตรี ≥ 20 | เจ้าของแผงชวนเล่นดนตรีหน้าร้านแลกข้าว | รับ / ขอค่าจ้าง / ปฏิเสธ |
| ผับ + ทักษะดนตรี ≥ 40 | เจ้าของผับเสนอสัญญานักดนตรี | รับ / ต่อรอง / ปฏิเสธ |
| หนี้ค้างชำระ + อายุ 18+ | ถูกเสนองานกะดึกรายได้สูงแต่เสี่ยง | รับ (เช่น โกดังสีเทา) / ขอผ่อนผัน / หางานปกติ |

กฎ: ทุกงานที่รับต้องผ่านการ์ดงานที่ลงทะเบียน ผลตอบแทนเป็นช่วงความน่าจะเป็น มีต้นทุนและผลข้างเคียงเสมอ (ไม่มีเงินฟรี) มีทางออกจากงานเสมอ (กัน Soft-lock)

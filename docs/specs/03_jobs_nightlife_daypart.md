### 1.1 งานความสามารถ (`Talent Gigs`) ตามอายุ `[ใหม่ · 3.3.3]` `[ยืนยัน ตัวเลข]`
> งานความสามารถ = หารายได้จากทักษะที่ตัวเองมี เช่น เปิดหมวกร้องเพลง แข่งเต้นงานตลาด/งานวัด ประกวดวาดรูป รับวาดภาพออนไลน์ ขายของ/ขนมกับผู้ปกครอง ติวหนังสือเด็กเล็ก (รายการเต็มใน `catalogs/activities.md` §5 และสเปก 07 §7) **ไม่นับเป็นแรงงาน** แต่ยังตรวจใน Engine เสมอ

| ช่วงอายุ | ทำได้หรือไม่ | เงื่อนไข | เพดาน / ข้อห้าม |
| :--- | :---: | :--- | :--- |
| **ต่ำกว่า 13 ปี** | ค้นพบและเรียนได้ **ยังไม่มีรายได้** | เริ่มเรียนทักษะ/ฝึกฝนได้ตามสเปก 05; ค่าขนมตามสเปก 02 §4 | ไม่มีรายได้จากงานความสามารถ; เหตุการณ์ที่เห็นความสามารถได้เฉพาะลางบอก/ผู้ใหญ่ชวนลอง |
| **13 – 14 ปี** | ได้ เฉพาะงานความสามารถ | **ต้องมีผู้ปกครองดูแล** และความสัมพันธ์กับผู้ปกครองถึงเกณฑ์ (>= 40); ทักษะถึงขั้นต่ำของกิจกรรมนั้น | เฉพาะ **เย็น/วันหยุด**; เพดานรายได้ **1,500 ฿/เดือน** (เกินแล้วส่วนเกินไม่เข้าตัว ผู้ปกครองเก็บให้); รวมเรียน+กิจกรรม <= 48 ชม./สัปดาห์; ห้ามงานกลางคืน/สถานบันเทิง/พนัน |
| **15 – 17 ปี** | ได้ ทำเองได้ รวมขายของออนไลน์ | ไม่ต้องมีผู้ปกครองดู (ผู้ปกครองยังเป็นตัวเลือกช่วยในเหตุการณ์เสี่ยงได้) | **ห้ามโอที / กะดึก / สถานบันเทิง / พนัน** ตามตารางเดิม; รวมเรียน+งาน <= 48 ชม./สัปดาห์; ไม่มีเพดานรายได้ตายตัวแต่ผ่านเพดานกลางของสเปก 05 |
| **ก่อน 15 ปี (ทุกกรณี)** | **ห้ามแรงงาน** | พาร์ตไทม์ งานประจำ โอที กะดึก งานในสถานบันเทิง | ห้ามเด็ดขาด ตรวจซ้ำใน Engine |

- **ผลตอบแทน:** ตามขั้นบันไดทักษะสเปก 05 (Lv. 1–30 รายได้เล็ก / 31–60 กลาง / 61+ ได้งานจริง) ไม่สร้างสูตรใหม่
- **ผูกกำพร้า/ฐานะไม่ดี `[อัปเดต · 3.3.3]`:** ตัวละครกำพร้าหรือฐานะยากจนปลดล็อกงานความสามารถเร็วขึ้นได้ที่ **13 ปี โดยมีผู้ปกครองทดแทน** (ญาติ/ครู/มูลนิธิ/ผู้ดูแลเด็ก) เป็นผู้ดูแล แทนเงื่อนไขความสัมพันธ์ผู้ปกครอง
- **ความเสี่ยงแบบชีวิตจริง:** โดนโกงค่าจ้าง, โดนไล่ที่ขายของ, ลูกค้าเบี้ยว (ผลพลาดต้องยังเล่นต่อได้ CORE §6.1)

## 2. ระบบกะงาน (`WorkShiftType`) และการล็อกช่องในกริดตารางแผนชีวิต
จัดการใน `src/engine/planner.ts` (`getSlotActivity`):
1. `morning-afternoon` (กะปกติ 09:00–17:00): ล็อกช่อง **เช้า + บ่าย** (วันธรรมดา)
2. `afternoon-evening` (กะบ่าย-เย็น 13:00–21:00): ล็อกช่อง **บ่าย + เย็น**
3. `night-morning` (กะดึก 20:00–06:00): ล็อกช่อง **ดึก + เช้า** (ได้ค่าแรงกะดึกเพิ่ม `+15%` แต่เพิ่มความเครียดและลดเวลาเจอครอบครัว)
4. `day_long` (กะยาว เช่น แพทย์เวร/ช่างหน้างาน): ล็อกช่อง **เช้า + บ่าย + เย็น** (หากเลือกพรีเซ็ตโหมงาน ระบบจะขยับช่อง `work_overtime` ไปลงช่องว่างถัดไปหรือวันหยุดอัตโนมัติ)
5. `flexible` (งานอิสระ/ฟรีแลนซ์): ไม่ล็อกช่องตายตัว ผู้เล่นเลือกวางช่องทำงานเองในกริด

## 3. การคำนวณรายได้โอทีและงานเสริมจากกริด (`Phase 3.2.2-P1`)
- รายได้จาก `work_overtime` คำนวณจากจำนวนชั่วโมงจริงที่วางในกริด (`SLOT_HOURS`) คูณอัตราค่าจ้างรายชั่วโมงฐาน × `1.5` (ต้องมีงานประจำที่ `overtimeAllowed !== false` และไม่เกิน 2 ช่องโอทีต่อสัปดาห์ในโหมดมาตรฐาน หรือไม่เกินเพดาน 64 ชม. รวม)
- การเชื่อมโยงไป **Phase 3.4**: เมื่อทำท่อสมัครงาน จะให้ผู้เล่นเลือกกะงานตอนเซ็นสัญญาและต่อรองเงินเดือนได้จริง

## 1. พรีเซ็ตวิถีชีวิต (`Lifestyle Presets`)
- พรีเซ็ตวิถีชีวิตทำหน้าที่เป็น **"แม่แบบทางลัด (Grid Templates)"** เมื่อผู้เล่นกดเลือกพรีเซ็ต ฟังก์ชัน `applyPresetTemplate()` จะไปวางกิจกรรมลงในกริด `character.planner.grid` ให้อัตโนมัติ (โดยไม่ทับช่องที่ถูกล็อกด้วยงานประจำหรือโรงเรียน)
- พรีเซ็ตจะปลดล็อกและล็อกตามช่วงวัยและสถานะจริง:
  - วัยเด็กเล็ก (`toddler` 0–5 ปี): มีเฉพาะพรีเซ็ตวัยเตาะแตะ
  - วัยเรียน (`child` / `teen`): `balanced` (สมดุล), `study_hard` (ขยันเรียน), `playful_social` (เล่นสนุก/สังสรรค์), `hobby_focus` (ซุ่มฝึกงานอดิเรก), `family_helper` (ช่วยงานบ้าน)
  - วัยผู้ใหญ่ (`young_adult` / `mid_adult` / `senior`): `balanced` (สมดุล), `hustle` (โหมงาน/โอที — เติมช่อง `work_overtime` อัตโนมัติ), `skill_grind` (ซุ่มอัปสกิล), `party_social` (ปาร์ตี้เข้าสังคม), `health_wellness` (รักสุขภาพ/ฟิตเนส), `homebody_gamer` (ติดบ้าน/เกมเมอร์), `family_devoted` (ทุ่มเทครอบครัว), `work_and_study` (ทำงานควบเรียน)

## 2. ระบบเลเวลทักษะ 1–5 และขั้นฝึก 3 ขั้น (`Skill Level & Training Tier`) `[อัปเดต · 3.3.1-FIX]` `[ยืนยัน]`
> แทนระบบเลเวล 0–100 ที่ขึ้นเร็วเกินไป (เดิมขึ้นได้ 3 แต้ม/สัปดาห์ และโรงเรียนปลดล็อกขั้นสนามจริงให้ academic อัตโนมัติ) ทุกทักษะ (`CoreSkillId` 6 ด้าน และ `DiscoveredSkillId` 7 ด้าน) ใช้ระบบเดียวกัน **ไม่มีเพดานตามวัยแยกต่างหาก** อายุถูกควบคุมผ่านเงื่อนไขของแต่ละขั้นฝึก

### 2.1 เลเวลและ XP
- ทักษะมี **Lv.1–Lv.5** แต่ละเลเวลมีแถบ XP ย่อย XP ที่ต้องใช้เพื่อเลื่อนไปเลเวลถัดไป:

| เลเวล | ชื่อเรียก | XP เพื่อเลื่อนขึ้น | ค่าคำนวณภายใน (0–100) |
| :-: | :-- | :-: | :-: |
| Lv.1 | เพิ่งเริ่ม | 100 | 0–19 |
| Lv.2 | พอทำได้ | 300 | 20–39 |
| Lv.3 | คล่อง | 700 | 40–59 |
| Lv.4 | ชำนาญ | 1,500 | 60–79 |
| Lv.5 | เชี่ยวชาญ | เต็มแล้ว | 90 (คงที่) |

- **ค่าคำนวณภายใน (0–100)** ใช้เป็นตัวเลขที่เงื่อนไขอื่นอ้างถึง (เช่น `academic >= 25` ในสายการเรียน) สูตร: `score = 20 × (Lv − 1) + floor(19 × สัดส่วนแถบ XP ปัจจุบัน)` สำหรับ Lv.1–4 และ Lv.5 = 90 UI แสดง Lv + แถบ XP ไม่ต้องโชว์ค่า 0–100
- **XP ต่อชั่วโมงฝึกพื้นฐาน** (ก่อนตัวคูณ): ฝึกเอง 0.25 · ลงคอร์ส 0.35 · สนามจริง 0.50 ที่ฝึก ~10 ชม./สัปดาห์ ได้ ~2.5 / ~3.5 / ~5 XP ต่อสัปดาห์
- **เพดานต่อสัปดาห์:** ไม่เกิน 6 XP ต่อทักษะ และไม่เกิน 10 XP รวมทุกทักษะ (กันฝึกรวดเดียว) ตัวคูณลดหลั่นภายในเลเวล: เริ่มเลเวล 1.00 ลดเป็น 0.85 ที่ปลายแถบ
- **เป้าหมายเวลา** (ฝึกจริงจัง ~10 ชม./สัปดาห์ ผู้ไม่มีพรสวรรค์): Lv.1→2 ≈ 1 ปี · Lv.2→3 ≈ 1.7 ปี · Lv.3→4 ≈ 3.8 ปี · Lv.4→5 ≈ 5.8 ปี (รวม ≈ 10+ ปี) ให้ปรับค่าฐานในข้อมูลโค้ดจนซิม 1000 ชีวิตได้ใกล้เป้า (±20%) พรสวรรค์ใหญ่ทำให้เร็วขึ้นไม่เกิน +30% (ดู §3) ไม่ข้ามขั้น
- **ย้ายเซฟเก่า (migration):** ค่าเก่า `s` (0–100) แปลงเป็น `Lv = min(4, floor(s/20)+1)` และ `s >= 80` เป็น Lv.5 โดยแถบ XP = สัดส่วน `(s mod 20)/20` ของแถบเลเวลนั้น ขั้นฝึกที่ปลดล็อก: `s >= 40` ถือว่าปลดล็อกขั้นคอร์ส `s >= 80` ถือว่าปลดล็อกขั้นสนามจริง

### 2.2 ขั้นฝึก 3 ขั้น (เพดานเก็บถาวรต่อทักษะ ห้ามตกกลับ)

| ขั้นฝึก | เงื่อนไข | ขึ้นได้ถึง | หมายเหตุ |
| :-- | :-- | :-: | :-- |
| **ฝึกเอง** | อายุ 6 ปีขึ้นไป ฝึกฟรีผ่านกิจกรรมหมวดพัฒนาตัวเอง/งานอดิเรก หรือเรียนในโรงเรียน | **Lv.2** | แถบ Lv.2 เติมเต็มได้แต่เลื่อนเป็น Lv.3 ไม่ได้จนกว่าจะปลดล็อกขั้นคอร์ส (แสดงสถานะ "รอปลดล็อกคอร์ส") |
| **ลงคอร์ส** | ผ่านคอร์สเรียนเสริม (ด้านล่าง) หรือเรียนตรงสายการเรียน/ชมรมที่ตรงทักษะ | **Lv.4** | อายุ 15 ขึ้นไปลงคอร์สเองได้ เด็กอายุน้อยกว่าเรียนผ่านเหตุการณ์ (เช่น `ev_child_music_class`) ได้ถึง **Lv.3** XP ที่ค้างในแถบนับต่อทันทีเมื่อปลดล็อก |
| **สนามจริง** | ต้องใช้จริง: ทำงานสายอาชีพที่ใช้ทักษะนั้น / เรียนมหาวิทยาลัยสายตรง / ลงแข่งขันหรือโปรเจกต์ระดับสูง (`competition_advanced`) **การเรียนในโรงเรียนไม่นับ** | **Lv.5** | ทักษะสายสังคม/สุขภาพ/ศิลปะใช้ประกวดหรือกิจกรรมระดับสูงแทนงานประจำได้ (กันทางตัน) |

- เพดานที่ปลดล็อกแล้วเก็บเป็นสถานะถาวรต่อทักษะ (`unlockedTier`) **ห้ามผูกกับ "คอร์สที่กำลังเรียน"** การลงคอร์สหลายทักษะสลับกันต้องไม่ทำให้เพดานของทักษะอื่นตกกลับ และ UI ต้องแสดงว่าเพดานปัจจุบันมาจากอะไร และจะปลดล็อกต่อได้อย่างไร

### 2.3 คอร์สเรียนเสริม (มีแบบเดียว)
- **8 สัปดาห์ · 4,000 บาท** (500 บาท/สัปดาห์ ตัดเป็นรายสัปดาห์) ต้องฝึกทักษะนั้นอย่างน้อย **6 ชม./สัปดาห์** ในกริดตารางแผนชีวิต
- ระหว่างเรียน XP ของทักษะนั้น **×1.5** (ไม่เกินเพดานต่อสัปดาห์)
- ขาดเรียนเกินกำหนด (ฝึกต่ำกว่า 6 ชม. เกิน 2 สัปดาห์) = **ไม่ผ่าน** เสียค่าที่จ่ายแล้วและไม่ปลดล็อก ลงใหม่ได้
- **ผ่านคอร์ส:** ปลดล็อกขั้นคอร์สถาวร (ถึง Lv.4) + ได้ **ใบประกาศ** (`certificate`) เก็บในสถานะตัวละคร ใช้เป็นหลักฐานในพอร์ต/สมัครงาน (ผลจริงที่ 3.3.2 / 3.4) อ่านเงื่อนไขเพิ่ม
- **ยกเลิก** ตัวเลือก 4 / 12 สัปดาห์เดิม คอร์สที่กำลังเรียนอยู่ในเซฟเก่าให้ใช้ต่อจนจบตามจำนวนสัปดาห์ที่เหลือ
- อ้างอิง: CORE §10 · BACKLOG A · SCHEMAS §4

## 3. ตัวคูณและผลตอบแทนลดหลั่น (`Modifiers & Diminishing Returns`)
- **ตัวคูณความถนัดและนิสัย:** คุณลักษณะแกนกลางที่ตรงสาย + นิสัย `disciplined_worker` บวกความเร็วฝึก หากทักษะตรงกับ **พรสวรรค์ที่ใช้งานอยู่ในช่อง** (ดูสเปก 07 §1.4) ของตัวละคร รับตัวคูณ XP ตามความแรง **เล็ก / กลาง / ใหญ่ = +10% / +20% / +30%** `[อัปเดต · 3.3.1-FIX]` `[ยืนยัน]` (ปรับจากค่าเดิม +15/30/50% ให้ตรงเพดานกลาง +40% ของพรสวรรค์ + ของขลัง + ฉายา รวมกัน) พรสวรรค์ "อัจฉริยะ" ใช้ตัวคูณนี้กับทุกทักษะ พรสวรรค์ใน lot ไม่ให้ผล
- **ผลตอบแทนลดหลั่น:** ตัวคูณลดหลั่นภายในเลเวล 1.00 → 0.85 (ดู §2.1) และหากความเครียด (`Stress`) สูงเกิน `80` XP ที่ได้ลดลงครึ่งหนึ่ง

### 3.1 งานอดิเรกคือ "สิ่งที่สนใจ" แท็กกิจกรรมทักษะ การค้นพบ และลางบอก `[อัปเดต · 3.3.1-FIX]` `[ยืนยัน]`
- **เลือกงานอดิเรกได้เลย** (เช่น วาดรูปและออกแบบ / เล่นดนตรีและร้องเพลง / ทำอาหารและชงเครื่องดื่ม / อ่านและงานเขียน / ฝึกภาษา / ซ้อมเต้นและจังหวะ / การแสดงและพิธีกร / เทคโนโลยีและโค้ดดิ้ง / งานช่างและประดิษฐ์ / ฝึกกีฬาและสมรรถภาพ) การเลือกเป็นแค่ "สิ่งที่สนใจ" **ไม่ได้ปลดล็อกทักษะทันที** ผู้เล่นต้องฝึกสะสมถึงเกณฑ์ก่อนจึงค้นพบ
- กิจกรรมทุกอย่างติด **แท็กทักษะ 1–3 แท็ก** ชั่วโมงที่ทำกิจกรรมที่ติดแท็กทักษะเฉพาะทางนั้นนับสะสมแยกต่อทักษะ
- **เกณฑ์ค้นพบ:** สะสม **24 ชั่วโมง** (หรือ >= 8 ครั้ง) ต่อทักษะ พรสวรรค์ตรงสายลดเกณฑ์ **25 / 40 / 60%** (เล็ก / กลาง / ใหญ่ = 18 / 14.4 / 9.6 ชม.) เมื่อสะสมถึง **1/3 ของเกณฑ์** (หลังลดแล้ว) ผู้มีพรสวรรค์ตรงสายเห็น **ลางบอก** (`ev_talent_hint`) ก่อนเปิดเผย ยังไม่โชว์ตัวเลข
- ผู้ไม่มีพรสวรรค์ตรงสายค้นพบได้เช่นกันแต่ได้เพียงสถานะ "ชอบ" (ปลดล็อกทักษะ ไม่มีโบนัสความเร็ว)
- เมื่อค้นพบ ให้ขึ้นเหตุการณ์ "ค้นพบความถนัดใหม่" (T1) ไม่ใช่ข้อความเงียบ ๆ
- ทักษะเสนอขยาย 6 ตัวใน `skills.md` (ถ่ายภาพ กีฬาต่อสู้ ทำสวน ดูแลคนและสัตว์ เกมวางแผน นำทีม) **ยังไม่ทำ** ใช้ระบบเดียวกันเมื่อผู้ใช้สั่งเพิ่มภายหลัง
- อ้างอิง: CORE §10 · BACKLOG A · SCHEMAS §4

## 4. ติวเข้ม/เรียนพิเศษ (แหล่งเดียว) `[อัปเดต · 3.3.2]`
- คอร์สติวสอบกลาง / ติวพอร์ต / ติวสัมภาษณ์ / ติวภาษา ใช้ **ช่องตารางหมวด `self_dev`** + ค่าคอร์ส ตาม `§2.3` (คอร์สเรียนเสริมปลดล็อกขั้นคอร์สถึง Lv.4 ตาม §2.2–2.3) ไม่สร้างสูตรใหม่
- ผลต่อ TCAS: ตัวคูณเรียนรู้ทักษะตรงสาย + โบนัสรอบ Portfolio / Admission ที่คำนวณจากชั่วโมงติวสะสมก่อนวันสอบ (ตัวเลขกำหนดใน 3.3.2 ต้องผ่านเพดานกลาง)
- ติวเตอร์ช่วยแก้ข้อจำกัด `lim_slow_learner` ได้ (`talents.md`)
- **สเปก 07 ชี้มาที่นี่ ไม่เขียนซ้ำ** (07 §4.2 ข้อ 5)
- อ้างอิง: CORE §10 · BACKLOG A · SCHEMAS §4

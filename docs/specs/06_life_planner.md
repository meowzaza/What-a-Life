# 06_life_planner.md — ตารางแผนชีวิต (Life Planner), เป้าหมายประจำปี, หมวดเวลาที่ปลดล็อกได้

ใช้กับ: Phase 3.2.2 (ตารางกริด + แคตตาล็อกกิจกรรม) และ Phase 3.2.3 (เป้าหมายประจำปี + ปฏิทิน + ปลดล็อก + เหตุการณ์ผูกตาราง)
อ่านคู่กับ: DESIGN.md, 01, 02, 03, 04, 05
ตัวเลขทุกตัวเป็นค่าตั้งต้นที่ปรับได้ ต้องอยู่ในตาราง src/data

## 0. แนวคิด

ผู้เล่น "จัดตารางชีวิตจริง" เป็นกริด ไม่ใช่เลื่อนสไลเดอร์ตัวเลข

- ตารางสัปดาห์ = 2 แบบ: วันธรรมดา (จ.-ศ.) และวันหยุด (ส.-อา.) แต่ละแบบมี 4 ช่อง เช้า / บ่าย / เย็น / ดึก
- แต่ละช่องเลือก "หมวดใหญ่ -> กิจกรรมย่อย" (ข้อ 3)
- ช่องที่ติดงานประจำ/เรียน/กะ/แอดมิตโรงพยาบาลถูกล็อก เห็นแม่กุญแจพร้อมเหตุผล
- ผลรายสัปดาห์ (พลังงาน ความเครียด ความสัมพันธ์ ทักษะ เงิน) แสดงพรีวิวสดก่อนยืนยัน
- พรีเซ็ตจาก 05 ยังอยู่ แต่เปลี่ยนบทบาทเป็น "แม่แบบที่เติมกริดให้" ไม่ใช่ตัวคำนวณ

## 1. หลักการ (ห้ามละเมิด)

1. แหล่งความจริงเดียว: "กริดตาราง (planner)" ชั่วโมง 168 ชม./สัปดาห์ที่ใช้คำนวณผลเป็นค่าที่ "คำนวณออกมาจากกริด" (derived) ไม่ใช่ข้อมูลที่แก้แยกอีกที่ ห้ามมีสองแหล่งแก้ได้
2. หน้าชั่วโมงเดิม (TimeAllocPanel) เปลี่ยนเป็นมุมมองอ่านอย่างเดียว "ดูเป็นชั่วโมง" ใต้กริด (แสดงว่ากริดแปลงเป็นกี่ชั่วโมง/หมวด)
3. Engine ตัดสิน pure ไม่ใช้ Math.random ผลเท่ากันที่ x1..x20
4. DayPlan/ฉากอ่านกิจกรรมจากกริด ลำดับความสำคัญ: เหตุการณ์/Scene Mode > ช่องล็อก (งาน เรียน กะ) > กิจกรรมในกริด > ค่าเริ่มต้นช่วงวัย
5. ไม่มีของฟรี: กิจกรรมมีต้นทุนเวลา เงิน พลังงาน และเงื่อนไข
6. กฎผู้เยาว์/แรงงาน (03 ข้อ 2) และขั้นบันไดทักษะ (05 ข้อ 4) ตรวจใน Engine
7. ข้อความ UI อยู่ใน src/data/uiText.ts ไร้ศัพท์เทคนิคและอิโมจิ

## 2. โครงช่องเวลาและการแปลงเป็น 168 ชม.

### 2.1 ช่อง
ช่วงเวลาตาม DESIGN.md: เช้า 05:00-11:59, บ่าย 12:00-16:59, เย็น 17:00-20:59, ดึก 21:00-04:59

### 2.2 ชั่วโมงต่อช่อง (ตาราง data ค่าตั้งต้น)
| ช่อง | ชั่วโมงที่ใช้ทำกิจกรรม |
| --- | --- |
| เช้า | 4 |
| บ่าย | 5 |
| เย็น | 4 |
| ดึก | 3 |

รวม 16 ชม./วัน ที่เหลือ 8 ชม./วัน = "นอนและกิจวัตรพื้นฐาน" (กิน อาบน้ำ เดินทางสั้นๆ)

### 2.3 กฎการแปลง (deterministic)
1. ช่องที่ล็อกด้วยงาน/เรียน ใช้ชั่วโมงจริงจากสัญญา/ตารางเรียน (JobDefinition, ตารางโรงเรียน) แทนชั่วโมงต่อช่อง
2. ช่องที่ผู้เล่นเลือกกิจกรรม ใช้ชั่วโมงต่อช่องจากตาราง 2.2 ลงในหมวดเวลาที่กิจกรรมนั้นสังกัด (timeCategory)
3. กิจกรรม "นอน" ในช่องดึก ให้ชั่วโมงนอนเพิ่มตามประเภท (นอนเต็มอิ่ม/นอนปกติ/นอนเร็ว) ตามตาราง data
4. ผลรวมรายสัปดาห์ = 5 x วันธรรมดา + 2 x วันหยุด แล้วจัดส่วนที่เหลือเข้าหมวด นอน/กิจวัตรพื้นฐาน ให้ครบ 168 เป๊ะ
5. validator: นอนต้องไม่ต่ำกว่าขั้นต่ำช่วงวัย (ตารางเดิมใน timeAlloc), งาน+เรียน+งานเสริม <= 48, ผู้เยาว์ไม่มีกลางคืน/ผับ ถ้าไม่ผ่านให้ปฏิเสธการยืนยันพร้อมเหตุผล ห้ามปัดค่าเงียบๆ
6. วันหยุดราชการ/ปิดเทอม: ช่องที่ปกติล็อกด้วยงาน/เรียนและวันนั้นหยุด ให้ใช้กิจกรรมจากแม่แบบวันหยุดแทน (ใช้ isThaiPublicHoliday, isThaiSchoolBreak ที่มีอยู่)

## 3. แคตตาล็อกกิจกรรม (หมวดใหญ่ -> กิจกรรมย่อย)

ทุกกิจกรรมมีฟิลด์: id, nameTh, majorGroup, timeCategory, allowedSlots (ช่องที่เลือกได้), sceneTag หรือ sceneId, evidenceKey, moneyCostPerSlot, minAge/maxAge, requires (เงื่อนไข), lockReasonTh, effectNotesTh (ข้อความสรุปผล)
ฉากต้องอ้างฉากที่มีใน sceneManifest; ถ้าฉากเหมาะยังไม่มี (ยิม ห้องสมุด ห้าง) ให้ใช้ฉากสำรอง (บ้าน หรือ street_shops) และบันทึก TODO ตาม 01 ข้อ 8 ห้ามสร้างฉากใหม่

| หมวดใหญ่ | กิจกรรมย่อย (ตัวอย่างและเงื่อนไข) | timeCategory |
| --- | --- | --- |
| งานและการเรียน | เรียน/ทำงานประจำ (ล็อก ตั้งโดยระบบ), โอที (ต้องมีงานประจำและงานอนุญาต), งานเสริม (ต้องมีบันทึกงานเสริมตามกฎ 05 ข้อ 3; ใน 3.3 มาจากท่อสมัคร) | งาน/เรียน, sideGig |
| พัฒนาตัวเอง | ฝึกเองที่บ้าน (เลือกทักษะ ขั้น 1), เข้าคอร์ส (ต้องมีคอร์ส active, ขั้น 2), ฝึกในสนามจริง (ต้องมีงาน/กิจกรรมที่เกี่ยวข้อง, ขั้น 3), อ่านหนังสือ/ทบทวนบทเรียน | พัฒนาตัวเอง |
| สังคมและครอบครัว | นัดเจอเพื่อน (ฉาก cafe/street_shops, มีค่าใช้จ่าย), เวลากับครอบครัว/ช่วยงานบ้าน (ฉากบ้าน), ปาร์ตี้/สังสรรค์กลางคืน (ฉาก nightlife_pub, 20+ หรือ 18+ ตาม pubVisitAge, ผู้เยาว์ล็อกถาวร) | สังคม, ครอบครัว, กลางคืน |
| ดูแลตัวเอง | ออกกำลังกาย/วิ่ง/ยิม (หลักฐานฝึกซ้อมร่างกาย), ดูแลผิว/แต่งตัว (เพิ่มภาพลักษณ์ มีค่าใช้จ่าย), พาตัวเองไปตรวจ/พักฟื้น | พัฒนาตัวเอง (ติดแท็ก fitness/selfcare) |
| งานอดิเรกและกิจกรรมพิเศษ | เล่นเกม/ดูซีรีส์/ทำงานอดิเรก, ชมรม (ปลดล็อก: เรียนมหาวิทยาลัย), สตรีม/ทำช่อง (ปลดล็อก: นิสัยติดเกมหรือความคิดสร้างสรรค์ถึงเกณฑ์) | งานอดิเรก |
| พักผ่อน | นอนเต็มอิ่ม, นอนปกติ, พักฟื้นลดเครียด (อยู่บ้านเงียบๆ) | นอน/งานอดิเรก ตามประเภท |

### 3.1 กฎเงิน
- ค่าใช้จ่ายรวมรายสัปดาห์ถูกหักใน onWeek ไม่ใช่ตอนกดเลือก
- ถ้าเงินไม่พอ: กิจกรรมที่มีค่าใช้จ่ายถูกสลับเป็นทางเลือกที่ฟรีโดยอัตโนมัติ (เช่น นัดเจอเพื่อน -> อยู่บ้าน) พร้อมบันทึกเหตุผลในบันทึกและ "ทำไม?" ห้ามเงินติดลบจากกิจกรรม
- ต่ำกว่า 15 ปี: กิจกรรมที่มีค่าใช้จ่ายไม่แสดงเป็นตัวเลือก (พ่อแม่ดูแลแล้ว) ยกเว้นระบุว่า "พ่อแม่จ่ายให้" ในตาราง data

### 3.2 กฎผูกกับทักษะ (05)
- "ฝึกเอง/เข้าคอร์ส/สนามจริง" ต้องเลือกทักษะที่ฝึก (ใช้โฟกัสทักษะของ 05 สูงสุด 2) และชั่วโมงในช่องนับเป็นชั่วโมงพัฒนาตัวเองของทักษะนั้นตามสูตร 05 ข้อ 4.2
- ถ้าทักษะติดเพดานขั้น กิจกรรมฝึกนั้นต้องแสดงเหตุผลและทางปลดล็อก (ใช้ข้อความจาก 05 ข้อ 4.5)

## 4. การทำงานของ UI (มือถือเป็นหลัก)

หน้า "ตารางแผนชีวิต" อยู่ในแท็บ "ชีวิต" (แทนส่วนวิถีชีวิตเดิมจาก 3.2.1) มีองค์ประกอบเรียงบนลงล่าง:

1. หัวเรื่อง + สรุปสถานะ (อายุ สถานะงาน/เรียน) + สวิตช์มุมมอง "ตารางสัปดาห์ / ปฏิทินรายปี" (ปฏิทินรายปีเปิดใน 3.2.3 ใน 3.2.2 ให้ทำแท็บไว้และแสดง "เร็วๆ นี้" ไม่ต้องใช้ศัพท์เทคนิค)
2. แถบ "ทางลัดจัดตาราง" (พรีเซ็ตจาก 05) เลื่อนแนวนอนได้ พรีเซ็ตที่ล็อกแสดงจางพร้อมเหตุผล กดแล้วเติมช่องที่ไม่ล็อกด้วยแม่แบบของพรีเซ็ต (ข้อ 5)
3. กริด 2 คอลัมน์: วันธรรมดา | วันหยุด แต่ละคอลัมน์ 4 แถว (เช้า บ่าย เย็น ดึก) แต่ละช่องแสดง ชื่อช่วงเวลา + กิจกรรม + ปุ่มเล็ก "เปลี่ยน" หรือแม่กุญแจ "ล็อก" สีและกรอบต่างกันตามหมวดใหญ่ (ใช้ธีมพาสเทลพิกเซลเดิม)
4. กดช่องที่ไม่ล็อก -> แผ่นล่าง (bottom sheet) เลือก "หมวดใหญ่" เป็นชิปแนวนอน แล้วเลือก "กิจกรรมย่อย" เป็นการ์ด แต่ละการ์ดแสดง ผลย่อ (ลูกศรขึ้น/ลง ไม่ใช่ตัวเลขดิบ), ค่าใช้จ่ายต่อสัปดาห์, เงื่อนไข ถ้าล็อกแสดงเหตุผลและทางปลดล็อก
5. กรอบ "ผลคาดการณ์รายสัปดาห์": พลังงาน ความเครียด ความสัมพันธ์ ทักษะที่จะโต เงินสุทธิ และ "ฉากที่จะเห็น" คำนวณจาก Engine จริง (ฟังก์ชัน preview เดิม ต่อยอด) พร้อมแถบเตือนสีแดงเมื่อผิดกฎ (เช่น นอนต่ำกว่าขั้นต่ำ)
6. ปุ่ม "ยืนยันแผน" (ใช้ผลตั้งแต่วันถัดไปในเกม) และ "ยกเลิกการแก้ไข" แผนที่ยังไม่ยืนยันแสดงป้าย "ฉบับร่าง" ปิดหน้าโดยไม่ยืนยัน = ไม่เปลี่ยนอะไร
7. ลิงก์พับได้ "ดูเป็นชั่วโมง" (อ่านอย่างเดียว) แสดงชั่วโมงต่อหมวดที่แปลงจากกริด

ข้อจำกัด UI: ห้ามแผงใหม่บังฉากพิกเซลหลักบนหน้าหลัก, แถบเวลาติดขอบจอคงเดิม, แผ่นล่างปิดได้ด้วยการแตะนอกกรอบ, ใช้งานได้ที่ความกว้าง 360-400 px

## 5. พรีเซ็ตกลายเป็นแม่แบบกริด

- สร้าง `src/data/lifestyleTemplates.ts`: แต่ละพรีเซ็ตมีแม่แบบ 2 ชุด (วันธรรมดา/วันหยุด) ระบุกิจกรรมของแต่ละช่อง ต่อช่วงวัยหลัก (เด็กเรียน, วัยรุ่น, ผู้ใหญ่ทำงาน, ผู้ใหญ่ไม่มีงาน, สูงวัย)
- กดพรีเซ็ต = เขียนเฉพาะช่องที่ไม่ล็อก แล้วผ่าน validator เดียวกัน
- ตารางพรีเซ็ตแบบ delta ชั่วโมงของ 05 เก็บไว้เพื่อย้ายเซฟ (migration) เท่านั้น ห้ามใช้คำนวณหลักอีก
- ทิศทางของแม่แบบ (ตัวอย่าง): ซุ่มฝึกทักษะ = เย็นวันธรรมดาเป็น "ฝึกเอง/คอร์ส" และวันหยุดบ่ายเป็นฝึก; ปาร์ตี้เข้าสังคม = เย็น/ดึกเป็นนัดเพื่อน/สังสรรค์ (ผู้ใหญ่) หรือเพื่อนฝูง (ผู้เยาว์); ติดบ้าน = ช่องว่างเป็นงานอดิเรก; พักฟื้น = ดึกนอนเต็มอิ่ม ช่องว่างพักฟื้น

## 6. ย้ายเซฟจาก 3.2.1

- เซฟที่มีพรีเซ็ต: สร้างกริดจากแม่แบบของพรีเซ็ตนั้นตามช่วงวัย/สถานะ
- เซฟที่เป็น 'custom' (ชั่วโมงกำหนดเอง): สร้างกริดจากพรีเซ็ต balanced แล้วบันทึกในไทม์ไลน์ว่า "ตารางถูกจัดใหม่เป็นแบบสมดุล" ห้ามปัดค่าเงียบ
- ฟิลด์ชั่วโมงเดิมใน state ยังอ่านได้เพื่อเทียบ แต่ค่าคำนวณหลักมาจากกริดเท่านั้น

## 9. Phase 3.2.3: เป้าหมายประจำปี, ปฏิทิน, หมวดที่ปลดล็อก, เหตุการณ์ผูกตาราง

### 9.1 เป้าหมายประจำปี (Annual Focus)
- ตั้งได้ตั้งแต่อายุ 13 ปีขึ้นไป ตอนวันเกิด (ผู้เล่นกดข้ามได้ ถ้าข้ามใช้เป้าหมายเดิมหรือ "ไม่ระบุ") และเปลี่ยนได้ตลอดปีแต่ไม่เกินปีละ 2 ครั้ง
- ตัวเลือก: เก็บเงิน, ซุ่มพัฒนาทักษะ/เปลี่ยนสายงาน, ฟื้นสุขภาพกายใจ, ใกล้ชิดครอบครัว, ขยายเพื่อน/คอนเนกชัน, ตั้งใจเรียน, ไม่ระบุ
- ผล: (ก) แนะนำพรีเซ็ตที่เข้ากับเป้าหมาย (ไม่บังคับ) (ข) กิจกรรมที่ตรงเป้าหมายให้หลักฐานพฤติกรรมเพิ่ม 10% (ไม่ใช่โบนัสสเตตัสฟรี) (ค) ตอนวันเกิดถัดไป "สรุปปีที่ผ่านมา" รายงานผลจากข้อเท็จจริง (เงินออมที่เปลี่ยน ทักษะที่โต ความเครียดเฉลี่ย ฯลฯ) ด้วยเทมเพลต ไม่ใช้ AI
- ห้ามบล็อกการเล่น ห้ามเด้งซ้ำถ้ามี T3 ค้าง

### 9.2 ปฏิทินรายปี (อ่านอย่างเดียว + ปักหมุด)
- แสดง: วันเกิด, วันหยุดราชการ/ปิดเทอม (clock.ts), ช่วงสอบ/เปิดเทอมถ้ามีข้อมูล, วันสิ้นสุดคอร์สที่ลงไว้, นัดหมายที่ผู้เล่นปักเอง
- Fog of Knowledge: ห้ามเปิดเผยเหตุการณ์ผลหน่วงเวลา (Echo) ที่ผู้เล่นยังไม่ควรรู้ แสดงเฉพาะลางบอกเหตุที่ระบบปล่อยแล้ว
- ใช้ข้อมูลจาก Engine ไม่สร้างวันสำคัญใหม่เอง

### 9.3 หมวดกิจกรรมที่ปลดล็อกได้ (Engine ตัดสินจากเกณฑ์ที่ตรวจได้ ไม่ใช่ AI)

### 9.6 เกณฑ์ตรวจรับ 3.2.3
1. ตั้ง/เปลี่ยนเป้าหมายประจำปีได้ ไม่เกินปีละ 2 ครั้ง ข้ามได้ ไม่บล็อกเวลา
2. ปฏิทินแสดงเฉพาะข้อมูลที่ผู้เล่นควรรู้ ไม่เปิดเผยผลหน่วงเวลาที่ซ่อน
3. กิจกรรมที่ปลดล็อกตรงเงื่อนไข ข้อ 9.3 และล็อกคืนอย่างสุภาพเมื่อนิสัยจาง
4. Storylet 24 ใบผ่าน Validator ทั้งหมด (ผู้เยาว์ปลอดภัย ฉากมีใน manifest เพดานเงินถูกต้อง)
5. บังคับเกิดเหตุการณ์แต่ละใบด้วยปุ่ม Dev ได้
6. seed เดียวกัน x1 กับ x20 ได้ผลเท่ากัน (streak ไม่ขึ้นกับความเร็ว)

# ระบบที่อยู่อาศัย (เช่า / ซื้อเงินสด / กู้ซื้อ / ผ่อนดาวน์ / เช่าซื้อ / บ้านครอบครัว)

เกม ชีวิตจริงยิ่งกว่านิยาย · เอกสารสเปกสำหรับ Engine และ AI · ฉบับที่ 1

ใช้คู่กับ `01_scene_catalog_v2.md` (ฉากบ้าน 7 แบบ) และ `03_jobs_nightlife_daypart.md` (รายได้ที่ใช้จ่ายค่าที่อยู่)

## 0. หลักการ

1. Engine ตัดสินทุกตัวเลข (ราคา ค่าเช่า ดอกเบี้ย การอนุมัติกู้ การยึด) AI เล่าเรื่องและเสนอเหตุการณ์ได้ แต่ห้ามตั้งราคาหรืออนุมัติสินเชื่อเอง
2. ราคาทั้งหมดในเอกสารนี้เป็น **ค่าตั้งต้นระดับกรุงเทพฯ (ปี 2569)** ปรับด้วยตัวคูณภูมิภาคและซิมหมื่นชีวิตทีหลัง ทุกค่าอยู่ในตาราง data ไม่ฝังในโค้ด
3. ที่อยู่ = ฉากบ้าน (scene) x รูปแบบการถือครอง (tenure) ฉากเดียวกันอยู่ได้หลายแบบ เช่น คอนโดกลางเมือง จะเช่า ซื้อสด ผ่อนธนาคาร หรือผ่อนดาวน์ก็ได้
4. ตัวละครอายุต่ำกว่า 18 ไม่ทำสัญญาเช่า/ซื้อ/กู้ได้เอง ที่อยู่ตามผู้ปกครองเท่านั้น (ผู้เล่นเลือกรูปแบบการถือครองไม่ได้จนกว่าจะบรรลุนิติภาวะ ตามกฎ isMinor เดิม)

## 3. ค่าเริ่มต้นการเช่า (`rent`)

- สัญญามาตรฐาน 12 เดือน (ห้องเช่า/แฟลตมีรายเดือน) ต่อสัญญาได้
- เงินที่ต้องมีตอนเริ่ม: มัดจำ 2 เดือน + ล่วงหน้า 1 เดือน (รวม 3 เท่าของค่าเช่า) บ้านชนบทที่เช่ากับญาติอาจไม่มี
- ค่าน้ำ-ไฟ-เน็ตแยกจากค่าเช่า (ดูข้อ 8)
- เจ้าของบ้านเป็น NPC มีนิสัย (ใจดี / เจ้าระเบียบ / เอาเปรียบ / ขี้หนี้) ผลต่อเหตุการณ์: ขึ้นค่าเช่า 3-10% ต่อปี (สูงกว่าถ้าย่านเริ่มฮิต) ซ่อมช้า หักมัดจำเกินจริง ไล่ออกเพราะขายตึก
- รูมเมต: หารค่าเช่า แต่ต้องสุ่มนิสัยรูมเมตตามที่ตกลงในเอกสาร NPC
- ค่าเช่าเกิน 40% ของรายได้ = เตือน Stress สะสม ค่าเช่าเกิน 60% = อยู่ในโซนเสี่ยงค้างชำระ

## 4. ซื้อเงินสด (`own_cash`)

| รายการ | อัตรา |
| --- | --- |
| ค่าธรรมเนียมการโอน | 2% ของราคาประเมิน (ปกติแบ่งผู้ซื้อ/ผู้ขายครึ่งละ 1%) |
| ค่านายหน้า (ถ้าซื้อผ่านนายหน้า) | ผู้ขายจ่าย 3% |
| ค่าปรับปรุง/ซ่อมก่อนเข้าอยู่ | 0-15% ของราคา ตามสภาพ |
| ภาษีที่ดินและสิ่งปลูกสร้าง | บ้านหลังหลัก มูลค่าไม่เกิน 50 ล้านบาท ยกเว้น เกินนั้นอัตราต่ำ 0.02-0.05%; ที่อยู่อาศัยหลังอื่น 0.02-0.1% ตามมูลค่า (ค่าโดยประมาณ ปรับตามกฎหมายจริงภายหลังได้) |

ซื้อเงินสดหมดตัวเสี่ยง: ไม่มีเงินสำรอง เหตุการณ์ฉุกเฉินทำให้ต้องกู้นอกระบบ ควรมีเหตุการณ์เตือนเมื่อเงินสดหลังซื้อต่ำกว่าค่าครองชีพ 3 เดือน

## 5. ผ่อนดาวน์กับเจ้าของโครงการ (`developer_installment`)

เฉพาะคอนโด/โครงการใหม่ (`home_condo_mid`, `home_condo_premium`) ยังไม่ได้เข้าอยู่ตอนผ่อนดาวน์

1. จ่ายเงินจอง 5,000-30,000 บาท + เงินทำสัญญา 3-5% ของราคา
2. ผ่อนดาวน์รวม 10-20% ของราคา แบ่ง 24-36 งวดต่อเดือน (ตัวอย่าง: คอนโด 2.9 ล้าน ดาวน์ 10% ผ่อน 24 เดือน = 12,083 บาท/เดือน)
3. ช่วงนี้ **ยังไม่ได้เข้าอยู่** แต่ผู้เล่นต้องไปเช่าหรืออยู่ที่เดิมควบคู่ จึงเป็นภาระซ้อน
4. ก่อนโอน ต้องกู้ธนาคารส่วนที่เหลือ (ใช้กฎข้อ 6) ถ้ากู้ไม่ผ่านและหาเงินสดไม่ได้ ผู้เล่นเลือก: ขายใบจอง (ได้เงินคืน 0-70% ตามตลาด) หรือ ทิ้งดาวน์ (เสียทั้งหมด)
5. ราคาตลาดตอนโอนอาจต่างจากสัญญา (ขึ้น = กำไร / ลง = ขาดทุนบนกระดาษ)
6. เหตุการณ์: โครงการล่าช้า โครงการร้าง ผู้พัฒนาล้มละลาย (หายาก) ขายใบจองต่อได้กำไร

## 6. กู้ธนาคาร (`mortgage`)

### ข้อมูลตั้งต้นอ้างอิงตลาดไทย (ปี 2569)

- ดอกเบี้ย MRR ของธนาคารอยู่ราว 6.0-6.6% ต่อปี (มี.ค. 2569) ค่าตั้งต้นของเกม MRR = 6.3%
- ธนาคารมักเสนอโปรโมชัน 1-3 ปีแรก ดอกเบี้ยจริงราว 4.5-5.3% หลังจากนั้นลอยตัวที่ MRR ลบ 0.5-1.5
- **ค่าตั้งต้นของเกม:** ดอกเบี้ยเฉลี่ยตลอดสัญญา 5.2% ต่อปี แยกเป็น ปี 1-3 = MRR - 2.0 (4.3%) และปี 4 เป็นต้นไป = MRR - 0.8 (5.5%) ขยับตาม MRR ในเหตุการณ์เศรษฐกิจโลก
- ระยะผ่อนสูงสุด 30 ปี และอายุผู้กู้รวมระยะผ่อนไม่เกิน 70 ปี
- วงเงินสูงสุดบางโครงการถึง 100% ของราคาประเมิน ค่าตั้งต้นของเกม LTV = 90% (ดาวน์ 10%) บ้านหลังที่ 2 = 90% บ้านหลังที่ 3 ขึ้นไป = 70-80%

### สูตรอนุมัติ (Engine ตัดสิน เป็นสูตรแน่นอน + สุ่มเล็กน้อยจาก seed)

```
เงื่อนไขขั้นต่ำ: อายุ >= 20, รายได้ต่อเดือน >= 15,000, ทำงานหลังผ่านโปร >= 6 เดือน (พนักงานประจำ)
รายได้ที่นับ = รายได้เฉลี่ย 6-12 เดือน x ตัวคูณประเภทอาชีพ
  พนักงานประจำ 1.0 | ข้าราชการ 1.0 | เจ้าของกิจการ(มีงบ 12 เดือน) 0.8
  ฟรีแลนซ์ 0.6 | รายได้นอกระบบ/เงินสด 0.3 | ว่างงาน 0 (ไม่อนุมัติ)
DSR = (ค่างวดใหม่ + ผ่อนอื่นทั้งหมด) / รายได้ที่นับ  ต้อง <= 0.40
วงเงินสูงสุด = ((รายได้ที่นับ x 0.40) - ผ่อนอื่น) / ตัวคูณค่างวด(อัตรา, ปี)
ผลอนุมัติ = ผ่าน / ผ่านแต่วงเงินน้อยกว่าที่ขอ / ไม่ผ่าน
คะแนนเครดิต < 50 = ไม่ผ่าน; 50-65 = ผ่านแบบวงเงินลด หรือดอกสูงขึ้น +1%
ผู้กู้ร่วม: รวมรายได้และภาระหนี้ แต่ผูกพันทางกฎหมายทั้งคู่ (ผูกกับ NPC พ่อแม่/คู่/เพื่อน)
```

ตัวคูณค่างวดสูตรผ่อนเท่ากันทุกงวด: ค่างวด = เงินต้น x r / (1 - (1+r)^-n) โดย r = ดอกเบี้ยต่อเดือน, n = จำนวนงวด

## 7. เช่าซื้อ (`rent_to_own`)

- สำหรับคนที่ธนาคารไม่ปล่อยกู้ (อาชีพนอกระบบ ฟรีแลนซ์รายได้ผันผวน หรืออาคารเก่า)
- เงินดาวน์ 10-20% ผ่อน 5-15 ปี **ดอกเบี้ยคงที่ 5-8% ต่อปีแบบคิดจากต้นทั้งก้อน** (ดอกเบี้ยที่แท้จริงสูงกว่านั้นราว 1.7-2 เท่า) กรรมสิทธิ์ยังไม่ได้เป็นของผู้เช่าซื้อจนจ่ายครบ
- ผิดนัด 2-3 งวด = ถูกบอกเลิกสัญญา **เสียเงินที่จ่ายมาทั้งหมด** ยึดคืน
- ผูกกับเหตุการณ์: เจ้าของโครงการ/นายทุนท้องถิ่น (NPC) ใจดี/เอาเปรียบ

## 9. มูลค่าทรัพย์สินและการขาย

### แนวโน้มราคาต่อปี (ก่อนหักเงินเฟ้อ ปรับด้วยเหตุการณ์เศรษฐกิจ)

| ประเภท | เฉลี่ย/ปี | ความผันผวน |
| --- | --- | --- |
| แฟลต/ห้องเช่าเก่า | -1% ถึง +1% | ต่ำ |
| บ้านไม้ชนบท (รวมที่ดิน) | +1% ถึง +3% | ต่ำ |
| ห้องแถว/บ้านพร้อมร้าน | +1% ถึง +4% | กลาง |
| คอนโดกลางเมือง | 0% ถึง +3% | กลาง |
| บ้านเดี่ยว/บ้านไม้ไทย | +2% ถึง +4% | กลาง |
| คอนโดหรู/บ้านหรู | +1% ถึง +5% | สูง |

เหตุการณ์ระดับโลก (ฟองสบู่ ถดถอย นโยบายใหม่) ปรับราคา -20% ถึง +20% ภายใน 1-3 ปี

### ขั้นตอนการขาย

1. ตั้งราคาประกาศ (ระบบแนะนำราคาตลาด ± 15%) ลงนายหน้าหรือขายเอง
2. เวลาขายตามสภาพคล่อง: แฟลต/ชนบท 3-12 เดือน, คอนโด 2-8 เดือน, บ้านเดี่ยว 3-10 เดือน, ของแพง 6-24 เดือน
3. ค่าใช้จ่ายผู้ขาย: ค่าโอนครึ่งหนึ่ง 1% + ภาษีธุรกิจเฉพาะ 3.3% (ถ้าถือครองไม่ถึง 5 ปี) + ภาษีหัก ณ ที่จ่าย + นายหน้า 3% (ตัวเลขโดยประมาณ)
4. ถ้ายังมีหนี้จำนอง ต้องปิดบัญชีก่อนโอน ถ้าขายได้น้อยกว่าหนี้ ผู้เล่นต้องหาเงินส่วนต่างหรือขายขาดทุนต่อรองกับธนาคาร

## 10. ผิดนัดชำระ ยึด ไล่ออก

| ระยะเวลา | เช่า | กู้ซื้อ/เช่าซื้อ |
| --- | --- | --- |
| ค้าง 1 เดือน | ค่าปรับ 1-5%, เจ้าของเตือน | ค่าปรับ 1.5-3% ต่อเดือน, Stress เพิ่ม |
| ค้าง 2 เดือน | หนังสือเตือน, อาจไล่ออก | หนังสือทวงถามจากธนาคาร, คะแนนเครดิตลด 15 |
| ค้าง 3 เดือน | ไล่ออก ยึดมัดจำ ข้าวของโดนยึดไว้ | บอกเลิกสัญญา เริ่มกระบวนการยึด |
| ค้าง 6+ เดือน | ถูกฟ้องขับไล่ | ยึดทรัพย์ประมูล ได้ราว 60-75% ของราคาตลาด ถ้าขายได้ต่ำกว่าหนี้ ส่วนต่างยังเป็นหนี้ต่อ |

ทางรอด (กัน Soft-lock): ขอผ่อนผัน (สำเร็จตามเครดิตและความสัมพันธ์กับเจ้าของ) ขายก่อนโดนยึด ย้ายไปบ้านครอบครัว/เพื่อน (ถ้ามีความสัมพันธ์ดีพอ) หางานเสริม (ดู `03_jobs_nightlife_daypart.md`) ขอกู้ปรับโครงสร้างหนี้ การพักอาศัยชั่วคราว (หอพักถูก ห้องรวมกับคนอื่น)

## 11. ตัวเลือกการย้ายที่อยู่ (UI/ขั้นตอน)

1. ผู้เล่นเปิดหน้า "ที่อยู่" ระบบสร้างรายการประกาศ 3-6 รายการตามภูมิภาค งบ และฐานะ (สุ่มจาก seed) แต่ละรายการระบุฉากบ้าน ทำเล ราคา/รูปแบบการถือครองที่เป็นไปได้
2. เลือกแล้ว Engine เช็กเงื่อนไข (เงินพอไหม ผ่านกู้ไหม) แสดงเหตุผลถ้าไม่ผ่าน
3. ต่อรองได้ด้วยทักษะเจรจา (ลดค่าเช่า 0-10% / ลดราคาซื้อ 0-8%)
4. มีเหตุการณ์หลอก: ประกาศปลอม (โอนมัดจำแล้วหาย) ห้องไม่ตรงปก นายหน้าเอาเปรียบ
5. ย้ายออกใช้เวลา 1-3 วัน มีค่าใช้จ่ายขนย้าย 1,000-30,000 บาท ตามฉากและระยะทาง ย้ายข้ามภูมิภาคเปลี่ยนสังคมและตัวคูณทั้งหมด

## 13. โครงข้อมูลที่แนะนำ (TypeScript แนวคิด)

```ts
type Tenure = 'family'|'rent'|'own_cash'|'mortgage'|'developer_installment'|'rent_to_own'|'inherited';

interface Dwelling {
  id: string;
  sceneId: string;           // เช่น 'home_condo_mid'
  tenure: Tenure;
  regionId: string;
  address: string;           // ชื่อที่สร้างตอนสุ่ม (ลงทะเบียนในฐานข้อมูล)
  sizeSqm?: number;
  marketValue?: number;      // ณ ปัจจุบัน
  purchasePrice?: number;
  purchasedOnDay?: number;
  landlordNpcId?: string;
  monthlyRent?: number;
  deposit?: number;
  mortgage?: Mortgage;
  downInstallment?: { remaining: number; perMonth: number; monthsLeft: number };
  monthlyRunningCost: number;  // น้ำไฟ ส่วนกลาง ซ่อม
}

interface Mortgage {
  principalRemaining: number;
  rateByYear: number[];       // ปีที่ 1-3, 4+
  termMonthsLeft: number;
  paymentPerMonth: number;
  missedMonths: number;
  coBorrowerNpcId?: string;
}
```

Effect ที่ AI/เหตุการณ์ใช้ได้ (union จำกัด): `MoveIn`, `PayRent`, `RaiseRent`, `Evict`, `StartMortgage`, `MissPayment`, `ForeclosureStep`, `SellDwelling`, `ChangeMarketValue` ห้ามมี Effect ที่ตั้งราคาหรือสร้างหนี้ตามใจ

## 14. ตัวอย่างเส้นทางชีวิต (ให้ซิมทดสอบ)

1. **คนทำงานบริษัท** เริ่ม 22 ปี เช่าคอนโดกลางเมือง 13,000 รายได้ 25,000 (ค่าเช่าเกิน 40%: เครียด) → อายุ 28 รายได้ 55,000 ผ่านกู้ได้ซื้อคอนโด 2.9 ล้าน ผ่อน 14,332 → อายุ 35 ขายได้กำไร หรือผ่อนต่อ
2. **ลูกร้านค้า** อยู่บ้านครึ่งไม้พร้อมร้านกับพ่อแม่ (family) → สืบทอดร้านเป็น inherited → ญาติแย่งสมบัติ
3. **ฟรีแลนซ์/งานนอกระบบ** รายได้ไม่นิ่ง กู้ธนาคารไม่ผ่าน → เช่า หรือเช่าซื้อห้องแถวดอกแพง → ผิดนัดแล้วเสียดาวน์

## 15. หมายเหตุสำคัญ

- ราคาและอัตราทั้งหมดเป็น **ค่าตั้งต้นเพื่อความสมเหตุสมผล** ไม่ใช่ข้อมูลเชิงกฎหมาย/การเงินที่ใช้ตัดสินใจจริง ปรับด้วยซิมหมื่นชีวิตเพื่อให้ผลลัพธ์ เช่น สัดส่วนผู้เป็นเจ้าของบ้านตามช่วงอายุ ไม่ผิดธรรมชาติ
- ตัวอย่างเป้าสัดส่วนในซิม (ค่าตั้งต้นเพื่อใช้ปรับ): อายุ 30 ราว 25-30% ซื้อบ้านแล้ว, อายุ 45 ราว 55-65%, อายุ 60 ราว 70-80% (รวมมรดกและบ้านครอบครัว)

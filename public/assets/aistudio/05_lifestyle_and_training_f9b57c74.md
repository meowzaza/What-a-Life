## 1. พรีเซ็ตวิถีชีวิต (`Lifestyle Presets`)
- พรีเซ็ตวิถีชีวิตทำหน้าที่เป็น **"แม่แบบทางลัด (Grid Templates)"** เมื่อผู้เล่นกดเลือกพรีเซ็ต ฟังก์ชัน `applyPresetTemplate()` จะไปวางกิจกรรมลงในกริด `character.planner.grid` ให้อัตโนมัติ (โดยไม่ทับช่องที่ถูกล็อกด้วยงานประจำหรือโรงเรียน)
- พรีเซ็ตจะปลดล็อกและล็อกตามช่วงวัยและสถานะจริง:
  - วัยเด็กเล็ก (`toddler` 0–5 ปี): มีเฉพาะพรีเซ็ตวัยเตาะแตะ
  - วัยเรียน (`child` / `teen`): `balanced` (สมดุล), `study_hard` (ขยันเรียน), `playful_social` (เล่นสนุก/สังสรรค์), `hobby_focus` (ซุ่มฝึกงานอดิเรก), `family_helper` (ช่วยงานบ้าน)
  - วัยผู้ใหญ่ (`young_adult` / `mid_adult` / `senior`): `balanced` (สมดุล), `hustle` (โหมงาน/โอที — เติมช่อง `work_overtime` อัตโนมัติ), `skill_grind` (ซุ่มอัปสกิล), `party_social` (ปาร์ตี้เข้าสังคม), `health_wellness` (รักสุขภาพ/ฟิตเนส), `homebody_gamer` (ติดบ้าน/เกมเมอร์), `family_devoted` (ทุ่มเทครอบครัว), `work_and_study` (ทำงานควบเรียน)

## 2. กฎขั้นบันไดทักษะ 3 ขั้น (`3-Tier Skill Progression Ladder`)
ทุกทักษะในเกม (ทั้ง `CoreSkillId` 6 ด้าน และ `DiscoveredSkillId` 7 ด้านที่จะเพิ่มใน Phase 3.3) ใช้เพดานและเงื่อนไขการเติบโต 3 ขั้นดังนี้:

| ขั้นทักษะ (Tier) | ช่วงเลเวล | เงื่อนไขการฝึกเพื่อขึ้นเลเวล | อัตราเติบโตพื้นฐาน & ต้นทุน |
| :--- | :---: | :--- | :--- |
| **ขั้นที่ 1: พื้นฐาน (Beginner)** | **Lv. 1 – 30** | **ฝึกเองได้ฟรี** ผ่านกิจกรรมหมวดพัฒนาตัวเอง/งานอดิเรกในกริดตารางแผนชีวิต หรือการเรียนในโรงเรียน | โตตามชั่วโมงฝึกในกริด × ตัวคูณความถนัด (หากไม่ลงคอร์สจะ **ตันที่ Lv.30**) |
| **ขั้นที่ 2: ชำนาญ (Intermediate)** | **Lv. 31 – 60** | ต้อง **ลงคอร์สเรียนเสริม / เวิร์กชอป** (เสียค่าคอร์สและกินเวลาในกริด) หรือ **เข้าชมรม / เรียนตรงสายการเรียน** | ต้องมีสถานะคอร์สหรือสายการเรียนรองรับจึงจะทะลุ Lv.30 ไปถึง **เพดาน Lv.60** ได้ |
| **ขั้นที่ 3: มืออาชีพ (Master)** | **Lv. 61 – 100** | ต้องใช้ **สนามจริง**: ทำงานในสายอาชีพที่ใช้ทักษะนั้นจริง หรือเลือกกิจกรรม **ลงแข่งขัน/โปรเจกต์ระดับสูง (`competition_advanced`)** | สำหรับทักษะสายสังคม/สุขภาพ/ศิลปะ สามารถใช้กิจกรรมระดับสูงหรือการประกวดปลดล็อกแทนงานประจำได้ (กันทางตัน Soft-Lock) |

## 3. ตัวคูณและผลตอบแทนลดหลั่น (`Modifiers & Diminishing Returns`)
- **ตัวคูณความถนัดและนิสัย:** คุณลักษณะแกนกลางที่ตรงสาย + นิสัย `disciplined_worker` บวกความเร็วฝึก; หากทักษะนั้นตรงกับ **พรสวรรค์** ของตัวละคร (`character.talents` ตาม CORE §10 / `catalogs/talents.md`) รับตัวคูณตามความแรง **เล็ก / กลาง / ใหญ่ (+15% / +30% / +50% `[ยืนยัน]` ไม่ใช่ `1.4x` ตายตัวแล้ว)** `[อัปเดต · 3.3.1]` พรสวรรค์ "อัจฉริยะ" เพิ่มความเร็วทุกทักษะ ส่วนข้อจำกัด (เช่น `lim_slow_learner`) ลดความเร็วจนกว่าจะแก้ได้ ผลรวมพรสวรรค์+ของขลัง+ฉายา ผ่านเพดานกลางเสมอ
- **ผลตอบแทนลดหลั่น:** ยิ่งเลเวลทักษะสูงขึ้น จำนวนชั่วโมงฝึกที่ต้องใช้ต่อการขึ้น 1 เลเวลจะเพิ่มขึ้นตามขั้นบันได และหากความเครียด (`Stress`) สูงเกิน `80` ประสิทธิภาพการฝึกจะลดลงครึ่งหนึ่ง

### 3.1 แท็กกิจกรรมทักษะ (ค้นพบอิสระ) และลางบอก `[ใหม่ · 3.3.1]`
- กิจกรรมทุกอย่างติด **แท็กทักษะ 1–3 แท็ก** เมื่อทำสะสมถึงเกณฑ์ (>= 8 ครั้ง หรือ >= 24 ชม.) ทักษะเฉพาะทางที่ตรงแท็กจึงเปิดเผย ไม่ต้องใช้กิจกรรม "ปลดล็อก" ตายตัวอย่างเดียว (ตารางใน `catalogs/skills.md`)
- พรสวรรค์ตรงสายลดเกณฑ์ค้นพบ 25 / 40 / 60% (เล็ก / กลาง / ใหญ่) ก่อนเปิดเผยมี **ลางบอก** ในเหตุการณ์เล็ก (`ev_talent_hint`) เช่น เรียนไวผิดปกติ ยังไม่โชว์ตัวเลข
- ทักษะเสนอขยาย 6 ตัวใน `skills.md` (ถ่ายภาพ กีฬาต่อสู้ ทำสวน ดูแลคนและสัตว์ เกมวางแผน นำทีม) ยังเป็น `[ยืนยัน]` ใช้ขั้นบันได 3 ขั้นเดียวกัน ถ้าผู้ใช้ยืนยัน
- อ้างอิง: CORE §10 · BACKLOG A · SCHEMAS §4

## 4. ติวเข้ม/เรียนพิเศษ (แหล่งเดียว) `[อัปเดต · 3.3.2]`
- คอร์สติวสอบกลาง / ติวพอร์ต / ติวสัมภาษณ์ / ติวภาษา ใช้ **ช่องตารางหมวด `self_dev`** + ค่าคอร์ส ตามขั้นบันไดข้อ 2 (คอร์สเรียนเสริมทำให้ทะลุ Lv.30 ได้) ไม่สร้างสูตรใหม่
- ผลต่อ TCAS: ตัวคูณเรียนรู้ทักษะตรงสาย + โบนัสรอบ Portfolio / Admission ที่คำนวณจากชั่วโมงติวสะสมก่อนวันสอบ (ตัวเลขกำหนดใน 3.3.2 ต้องผ่านเพดานกลาง)
- ติวเตอร์ช่วยแก้ข้อจำกัด `lim_slow_learner` ได้ (`talents.md`)
- **สเปก 07 ชี้มาที่นี่ ไม่เขียนซ้ำ** (07 §4.2 ข้อ 5)
- อ้างอิง: CORE §10 · BACKLOG A · SCHEMAS §4

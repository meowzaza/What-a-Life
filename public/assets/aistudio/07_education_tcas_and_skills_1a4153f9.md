## 1. ระบบทักษะ 2 ชั้น (Two-Tier Skill System) และพรสวรรค์ซ่อนเร้น

### 1.1 ทักษะหลัก 6 ด้าน (`CoreSkillId` — แสดงผลตั้งแต่ต้น)
1. `academic`: วิชาการและคำนวณ (คณิตศาสตร์ วิทยาศาสตร์ ตรรกะและความรู้ทั่วไป)
2. `tech`: เทคโนโลยีและดิจิทัล (คอมพิวเตอร์ เขียนโปรแกรม ซอฟต์แวร์ และอุปกรณ์ดิจิทัล)
3. `business`: ธุรกิจและการจัดการ (การตลาด การเงิน การบริหาร และการเจรจาต่อรอง)
4. `social`: การสื่อสารและเข้าสังคม (วาทศิลป์ การทำงานร่วมกับผู้อื่น และมนุษยสัมพันธ์)
5. `athletics`: ร่างกายและกีฬา (ความแข็งแรง ความอึด กีฬา และสุขภาพกาย)
6. `craft`: งานช่างและปฏิบัติการ (งานฝีมือ ซ่อมบำรุง งานเทคนิค และเครื่องจักร)

### 1.2 ทักษะเฉพาะทางที่ค้นพบได้ 7 ด้าน (`DiscoveredSkillId` — ซ่อนไว้จนกว่าจะปลดล็อก) `[อัปเดต · 3.3.1]`
> **ค้นพบอิสระ ไม่ใช่ปลดล็อกตายตัว:** กิจกรรมทุกอย่างติด "แท็กทักษะ" 1–3 แท็ก เมื่อทำสะสมถึงเกณฑ์ (>= 8 ครั้ง หรือ >= 24 ชม. หรือเหตุการณ์ลางบอก) ทักษะนั้นเปิดเผยได้ ไม่จำเป็นต้องเข้าชมรมหรือสายการเรียนที่ตรงเป๊ะ คอลัมน์ "ปลดล็อกจาก" ในตารางด้านล่างจึงเป็น **ตัวอย่าง ไม่ใช่รายการครบ** รายการเต็มและทักษะเสนอขยายอยู่ใน `catalogs/skills.md` อ้างอิง: CORE §10 · BACKLOG A · SCHEMAS §4
เก็บรายการที่ปลดล็อกแล้วไว้ใน `character.discoveredSkills: DiscoveredSkillId[]` จะยังไม่ปรากฏบนหน้าโปรไฟล์จนกว่าตัวละครจะทำกิจกรรมในตารางเวลา, เข้าชมรม, เลือกสายการเรียน, ลงคอร์สเสริม, ทำงานพาร์ตไทม์ หรือผ่านเหตุการณ์จุดประกาย:

| รหัสทักษะ (`DiscoveredSkillId`) | ชื่อทักษะภาษาไทย | รายละเอียดและช่องทางปลดล็อกในเกม (`Unlock Triggers`) |
| :--- | :--- | :--- |
| `visual_arts` | ศิลปะและการออกแบบ | วาดเส้น จิตรกรรม กราฟิกดีไซน์ แฟชั่น • **ปลดล็อกจาก:** กิจกรรมวาดรูป/ออกแบบในตาราง, ชมรมศิลปะ, สายศิลปกรรม ม.ปลาย, คอร์สเรียนศิลปะ |
| `music_vocal` | ดนตรีและการขับร้อง | ดนตรีไทย ดนตรีสากล ร้องเพลง แต่งเพลง • **ปลดล็อกจาก:** กิจกรรมซ้อมดนตรี/ร้องเพลงในตาราง, ชมรมดนตรีไทย/สากล, คอร์สเรียนดนตรี, เหตุการณ์แสดงงานโรงเรียน |
| `performing_acting` | การแสดงและศิลปะการละคร | แอ็กติ้ง ละครเวที บุคลิกภาพหน้ากล้อง พิธีกร • **ปลดล็อกจาก:** ชมรมการแสดง/ละครเวที, คอร์สการแสดงเสริม, อาสาเป็นพิธีกร/ตัวแทนรุ่น, เหตุการณ์แคสติ้ง |
| `dance_thai_modern` | นาฏศิลป์และการเต้น | นาฏศิลป์ไทย/รำไทย และเต้นสมัยใหม่ (Cover / Street Dance) • **ปลดล็อกจาก:** ชมรมนาฏศิลป์หรือชมรมเต้น, กิจกรรมซ้อมเต้น/รำไทยในตาราง, คอร์สเรียนเต้น, งานแสดงโรงเรียน |
| `culinary` | การทำอาหารและเครื่องดื่ม | อาหารไทย เบเกอรี่ และบาริสต้า • **ปลดล็อกจาก:** งานอดิเรกทำอาหาร/ชงกาแฟในตาราง, ช่วยงานครัวที่บ้าน, คอร์สทำอาหาร, พาร์ตไทม์ร้านอาหาร/คาเฟ่ |

| `literature_writing` | การเขียนและวรรณศิลป์ | เขียนนิยาย บทความ กวี และเขียนบท • **ปลดล็อกจาก:** กิจกรรมอ่านหนังสือ/เขียนนิยายในตาราง, ชมรมวรรณศิลป์/วารสารโรงเรียน, ส่งประกวดงานเขียน |

### 1.3 พรสวรรค์หลายชนิดและข้อจำกัดที่แก้ได้ (`talents`) `[อัปเดต · 3.3.1]`
> เปลี่ยนจากระบบเดิม "ทุกคนสุ่ม `hiddenAptitudes` 1–2 ด้าน ตัวคูณ `1.4x` ตายตัว" เป็นระบบตาม CORE §10 (ตัวเลขทั้งหมดยืนยันแล้ว รายการจริงอยู่ `catalogs/talents.md`)
- **จำนวน:** สุ่มแบบ Deterministic จาก seed ตอนสร้างชีวิต (`lifegen.ts`) **ตั้งแต่ 0 ถึงหลายอย่าง ไม่บังคับว่าทุกคนต้องมี** (ไม่มีเลย ~35% / 1 อย่าง ~40% / 2 อย่าง ~20% / 3+ ~5%)
- **ความแรง 3 ระดับ (เล็ก / กลาง / ใหญ่)** แทนตัวคูณเดียว (ผลต่อความเร็วฝึกกำหนดที่สเปก 05 §3)
- **ชนิด:** (1) ผูกทักษะ เช่น ดนตรี ภาษา ศิลปะ วิชาการ (2) ผูกบุคลิก เช่น การเจรจา (ใช้ต่อรองเงินเดือน/สัมภาษณ์ใน 3.4), เสน่ห์, ความจำ, สมาธิ (3) **อัจฉริยะ** เรียนรู้ทุกทักษะไวขึ้นและเจอพรสวรรค์อื่นไวขึ้น หายากกว่าชนิดอื่น
- **ผลไม่ใช่แค่ความเร็วฝึก:** โอกาสค้นพบทักษะ, เพดานเลเวล, โบนัสพอร์ต/ออดิชั่น, และปลดล็อก "ตัวเลือกพิเศษ" ในเหตุการณ์ (CORE §6.1)
- **ลางบอกก่อนเปิดเผย:** เหตุการณ์เล็ก (`ev_talent_hint`) เช่น เรียนไวผิดปกติ ยังไม่โชว์ตัวเลข เมื่อทำกิจกรรมตรงสายถึงเกณฑ์/ผ่านลางบอก จึงเปิดเผยป้าย **"มีพรสวรรค์"** + Toast ภาษาไทย (ไม่ใช้ศัพท์เทคนิค)
- **ข้อจำกัด (debuff) แก้ได้:** ใช้กฎสุ่มเกิดเดียวกัน และอาจเกิดเพิ่มระหว่างชีวิตตามเงื่อนไข ทุกข้อ **แก้ได้** เช่น `lim_slow_learner` (หัวช้า) แก้ด้วยขยันศึกษา/ติวเตอร์/กาชา
- **ได้พรสวรรค์ระหว่างชีวิต:** กาชาพรสวรรค์ (CORE §9, ราคาและอายุตามสเปก 03 §4) / เหตุการณ์ใหญ่หายาก / อัจฉริยะเจอเอง · **lot เก็บได้ไม่เกิน 5** นับรวมของที่เกิดมา
- **เพดานกลาง:** ผลรวมพรสวรรค์ + ของขลัง + ฉายา ต้องไม่เกินเพดานกลาง (ตัดสินใน 3.3.1)
- อ้างอิง: CORE §10 · BACKLOG A · SCHEMAS §4

## 2. โครงสร้างระดับชั้น เกรดเฉลี่ย (GPA) และการกลับไปเรียนต่อทุกวัย

### 2.1 ลำดับชั้นเรียน (`EducationLevel`) และแผนการเรียน
- `none` (0–5 ปี) -> `primary` (ประถม ป.1–ป.6, อายุ 6–11 ปี) -> `lower_secondary` (ม.ต้น ม.1–ม.3, อายุ 12–14 ปี)
- **ระดับมัธยมปลาย / สายอาชีพ (อายุ 15–17 ปี):** เลือกเรียนต่อได้ระหว่าง:
  - `upper_secondary` (ม.4–ม.6) แยก 4 แผนการเรียน (`highSchoolTrack`):
    1. `sci_math` (วิทย์-คณิต — ใช้ยื่นคณะสายแพทย์และวิศวะ)
    2. `arts_math` (ศิลป์-คำนวณ — เสริม `academic` + `business`)
    3. `arts_lang` (ศิลป์-ภาษา — ปลดล็อก `foreign_lang` ทันที)
    4. `arts_fine` (ศิลปกรรม/ดนตรี/การแสดง — ปลดล็อกทักษะสายศิลปะ/ดนตรี/นาฏศิลป์ตามที่เลือก)
  - `vocational` (ปวช. สายอาชีพ 3 ปี — เน้น `craft` / `tech` / `culinary` / `business` จบแล้วทำงานช่าง/บริการได้ทันทีหรือต่อ ป.ตรี ได้)
    - `[อัปเดต · 3.3.2]` สถาบันอาชีวะอ้างรหัส `voc_*` ใน `catalogs/institutions.md` (หมวด D) ปวช. (3 ปี) -> ปวส. (2 ปี) -> ป.ตรีต่อเนื่อง ได้ ผลแข่งทักษะอาชีวะได้ฉายา `edu_vocational_ace` อ้างอิง: CORE §4 · BACKLOG A · SCHEMAS §4
- **ระบบกลับไปเรียนต่อได้ทุกวัย (`Second-Chance Education` สำหรับคนหลุดจากระบบ อายุ 15+):**
  - `nfe_lower` (กศน. ม.ต้น) และ `nfe_upper` (กศน. ม.ปลาย): ใช้ช่องเวลาเย็นหรือวันหยุดในกริดตารางแผนชีวิต เรียนสะสมครบ 1.5–2 ปีเพื่อรับวุฒิ ม.3 หรือ ม.6 โดยไม่กระทบงานประจำ
  - `bachelor` (ป.ตรี 4 ปี) -> `master` (ป.โท 2 ปี) -> `doctorate` (ป.เอก 3 ปี)

### 2.2 ประเภทโรงเรียน (`SchoolTier`), เกรดเฉลี่ย (GPA) และ รด.
- **ประเภทโรงเรียน:** `school_temple` (โรงเรียนวัด — ฟรี), `school_public` (โรงเรียนรัฐ — ค่าเทอมต่ำ), `school_private` (โรงเรียนเอกชน — ค่าเทอมปานกลาง โบนัสวิชาการ/กิจกรรม), `school_international` (โรงเรียนนานาชาติ — ค่าเทอมสูงมาก ปลดล็อก `foreign_lang` ทันที) ผู้เล่นกดขอย้ายโรงเรียนได้ช่วงปิดเทอม (มี.ค.–เม.ย.)
- **การคำนวณ GPA (`0.00–4.00`):** คำนวณทุกสิ้นเทอม (ต.ค. และ มี.ค.) จากชั่วโมงเข้าเรียน + ชั่วโมงอ่านหนังสือทบทวน (`self_dev`) + ทักษะตรงสาย - ความเครียด (`Stress`)
  - หากสิ้นปี `GPA < 1.50` จะเกิดเหตุการณ์ **ติด ร. / มส.** ต้องเสียเวลาช่วงปิดเทอมซ่อมเกรด
  - หากได้รับทุนการศึกษา (`scholarshipMinGpa: 3.00`) แล้วสิ้นปีเกรดต่ำกว่าเกณฑ์ จะถูกตัดสิทธิ์ทุนทันที
- **เรียน รด. (นักศึกษาวิชาทหาร):** ตอนขึ้น ม.4 (อายุ 15 ปี) เลือกสมัครเรียน รด. ได้ (ใช้ช่องเวลาวันหยุด 1 ช่องตลอด 3 ปี ม.4–ม.6) เมื่อจบ ม.6 จะได้รับสถานะ `completedRotc = true` (ใช้ยกเว้นการเกณฑ์ทหารตอนอายุ 21 ปีใน Phase 7)

## 3. วิกฤตครอบครัวยากจนบีบให้ออกตอนจบ ม.3 (`Dropout Crisis Event`) `[อัปเดต · 3.3.1 / 3.3.3]`
> กติกากลาง CORE §6.1: ตัวเลือกปกติ **>= 4 ข้อ** ที่ต่างกันที่แนวทาง + ตัวเลือกพิเศษที่ปลดล็อกตามเงื่อนไข + ผลทุกข้อระบุ 5 ช่อง (ตรวจอะไร / โอกาส ต่ำ-กลาง-สูง / ผลสำเร็จ / ผลพลาด / ผลข้างเคียง) และต่อเหตุการณ์ไหน ผลพลาดต้องเล่นต่อสนุกได้ ไม่ใช่ทางตัน

เมื่อตัวละครเรียนจบ ม.3 (อายุ 14–15 ปี) และสถานะการเงินครอบครัวขัดสน (`poor` หรือหนี้สูง) จะบังคับเกิดการ์ด `T3 จุดเปลี่ยน`: **"อนาคตหลังจบ ม.3 เมื่อทางบ้านส่งไม่ไหว"** พร้อม **6 ทางเลือกปกติ** (ขั้นต่ำ 4 ตามกฎ) + ตัวเลือกพิเศษตามเงื่อนไข:
1. **ยอมออกจากโรงเรียนมาหางานช่วยทางบ้าน:** จบที่วุฒิ ม.3 ทันที (สามารถกดเรียน กศน. ม.ปลาย ทีหลังได้เมื่อพร้อม)
2. **ขอสอบชิงทุนเรียนต่อ ม.ปลาย/ปวช.:** ตรวจ `GPA >= 3.25` และ `academic >= 25` หากผ่านจะได้เรียนฟรีพร้อมค่าขนม แต่ต้องรักษาเกรด `>= 3.00` ทุกปี
3. **ขอเรียนต่อโดยทำงานพาร์ตไทม์ส่งตัวเองเรียน 100%:** (อายุ 15+) ได้เรียนต่อ แต่ต้องจัดตารางทำงานพาร์ตไทม์หลังเลิกเรียน/วันหยุดจ่ายค่าเทอมเอง
4. **ต่อรองขอให้ทางบ้านช่วยออกครึ่งหนึ่ง และเราหาเองครึ่งหนึ่ง:** ลดภาระค่าเทอมลง 50% (ตรวจความสัมพันธ์ครอบครัวระดับปานกลางขึ้นไป)
5. **อ้อนวอนขอร้องพ่อแม่อีกครั้ง:** ตรวจความสัมพันธ์ครอบครัวสูง + นิสัยพ่อแม่ หากสำเร็จ พ่อแม่จะยอมไป **กู้หนี้เพิ่ม** มาส่งเราเรียนจนจบ ม.6 (แต่หนี้ครอบครัวจะเพิ่มขึ้นเป็นภาระระยะยาว)
6. **ใช้ทักษะหาเงินส่งตัวเองเรียน** `[อัปเดต · 3.3.3]`: ปรากฏเมื่อมีทักษะถึงเกณฑ์งานความสามารถอย่างน้อย 1 อย่าง (สเปก 03 §1.1) และเป็น **กำพร้า / ฐานะไม่ดี / ครอบครัวสนับสนุนไม่ได้** ตรวจ ทักษะที่ใช้หาเงิน + ผู้ดูแล (ผู้ปกครอง/ญาติ/ครู/มูลนิธิ) หากสำเร็จ ได้เรียนต่อ ม.ปลาย/ปวช. โดยใช้รายได้งานความสามารถ (ไม่เกินเพดานสเปก 03) จ่ายส่วนหนึ่งของค่าเทอม ผลพลาด รายได้ไม่พอ/โดนโกงค่าจ้าง -> ตกไปตัวเลือก 4 หรือ 2 ได้ ผลข้างเคียง เหนื่อยสะสม เวลาเรียนลด ได้ฉายา `fam_self_made_kid`

**ตัวเลือกพิเศษที่ปลดล็อกตามเงื่อนไข (แสดงเมื่อเงื่อนไขครบ มิฉะนั้นโชว์แบบล็อกพร้อมเหตุผลภาษาไทย) `[อัปเดต · 3.3.1]`:**

## 4. ระบบคัดเลือกเข้ามหาวิทยาลัย TCAS (7 สถาบันตั้งต้น + สถาบันเพิ่มเติมใน catalog พร้อมคณะและสาขาเฉพาะตัว)

### 4.1 ทะเบียนสถาบันอุดมศึกษา `[ใหม่ · 3.3.2]` `[อัปเดต · 3.3.2]`
> **ตารางสถาบัน/คณะ/สาขา/ค่าเทอมเต็มย้ายไป `catalogs/institutions.md` แล้ว (ตอนนี้มี 40+ แห่ง: ภาคปกติ / ค่ำ-ออนไลน์ / นานาชาติ-ต่างประเทศ / อาชีวะ พร้อมทะเบียนสาขา `maj_*`)** ชื่อสถาบันทุกแห่งเป็นชื่อสมมติ ห้ามผสมชื่อจริง/ชื่อกลุ่มสถาบันจริง สเปกนี้เก็บเฉพาะกติกา
- **7 สถาบันตั้งต้นเดิม (รหัสคงเดิม):** `uni_health_science`, `uni_fine_culture`, `uni_humanities_soc`, `uni_tech_innovation`, `uni_commerce_hospitality`, `uni_regional_rajabhat` (ชื่อเปลี่ยนเป็น **"ม.ภูมิภาคและเทคโนโลยีประจำถิ่น"** ห้ามใช้ชื่อกลุ่มสถาบันจริง คงรหัสเดิมไว้จนกว่าจะเปลี่ยนพร้อมโค้ดใน 3.3.2), `uni_open_evening`
- **ชื่อเสียงเป็นตัวเลขที่กระทบโอกาสสมัครจริง `[ใหม่ · 3.3.2]`:** ทุกสถาบันมี `prestige` และ `competition` (1–100, ค่าใน catalog เป็น `[ยืนยัน]`) ใช้กำหนด คะแนนตัดแต่ละรอบ, ความยากแข่งขัน, โอกาสได้ทุน, น้ำหนักฉายา/พอร์ตตอนสัมภาษณ์ และโบนัสสมัครงานหลังจบ **ค่าเทอมเป็นอีกแกนหนึ่ง** ไม่ผูกกับ prestige
- **คณะ/สาขาเป็นน้ำหนักถ่วง ไม่ใช่เกณฑ์ขั้นต่ำเด็ดขาด `[อัปเดต · 3.3.2]`:** `คะแนนสมัคร = (ทักษะตรงสาย x น้ำหนัก) + (GPA x น้ำหนัก) + (tcasExamScore x น้ำหนัก, รอบ Admission) + โบนัสพอร์ต/ฉายา/สภา/ชมรม + ผลสัมภาษณ์` เทียบกับ `คะแนนตัด = f(prestige, competition, จำนวนที่นั่ง)` ผ่านเกณฑ์ทักษะแต่ไม่ถึงคะแนนตัด = ติดสำรอง/ไม่ติด (ไม่ใช่ตัดทิ้ง) (สูตรที่ `institutions.md` กติกาข้อ 1)
- **เกณฑ์ทักษะขั้นต่ำเดิมของ 7 สถาบัน** (เช่น แพทยศาสตร์ GPA >= 3.50 `academic >= 55`, ดุริยางคศาสตร์ `music_vocal >= 35`, วิศวกรรมศาสตร์ `tech >= 40` + `academic >= 45`, ครุศาสตร์ `academic >= 25` + `social >= 25`) อยู่ครบในแถวของแต่ละสถาบันใน `institutions.md` ใช้เป็น "น้ำหนักถ่วงฐาน" ตั้งต้น
- อ้างอิง: CORE §4 · BACKLOG A · SCHEMAS §4.1

### 4.2 รอบการรับสมัคร TCAS (3 รอบ) แรงเสียดทานจากครอบครัว และทางเลือกหลังเข้าเรียน `[อัปเดต · 3.3.2]`
1. **รอบที่ 1 แฟ้มสะสมผลงาน (`Portfolio`):** เปิดสำหรับสาขาศิลปะ ดนตรี การแสดง กีฬา อาหาร หรือผู้ที่มีทักษะเฉพาะทางถึงเกณฑ์ ไม่ใช้คะแนนสอบกลาง แต่ต้องผ่าน **การ์ดสอบปฏิบัติ/สัมภาษณ์เฉพาะสาขา 1–2 ข้อ**
   - **สัมภาษณ์ `[อัปเดต · 3.3.2]`:** รอบ Portfolio สายศิลปะ/ดนตรี/การแสดง/กีฬา/อาหาร มีสัมภาษณ์/สอบปฏิบัติ **100%** · รอบ Quota/Admission สุ่มตามเปอร์เซ็นต์ของสาขา (คอลัมน์ `สัมภาษณ์%` ใน `institutions.md`; แพทย์/การบิน/ความมั่นคง 100%) ผลสัมภาษณ์ตรวจทักษะ/ฉายา/บุคลิก (พรสวรรค์เจรจา/เสน่ห์ช่วยได้) -> ผ่านเด่น / ผ่าน / สำรอง / ไม่ผ่าน ผลพลาดต้องเล่นต่อได้
2. **รอบที่ 2 โควตาเรียนดี/ภูมิภาค (`Quota`):** ตรวจ `GPA >= 3.25` + คะแนนสอบกลางระดับปานกลาง
3. **รอบที่ 3 สอบคัดเลือกกลาง (`Admission`):** ต้องเข้า **"วันสอบวัดระดับเข้ามหาวิทยาลัย"** ในเดือนมีนาคม (หรือกดสมัครสอบรอบบุคคลทั่วไปสำหรับคนจบ กศน./เด็กซิ่ว) เพื่อรับคะแนน `tcasExamScore` (0–100) มายื่นเลือกอันดับได้สูงสุด 3 สาขา
4. **แรงเสียดทานจากครอบครัว (`Family Major Clash`):** หากครอบครัวมีค่านิยมเจ้าระเบียบ/คาดหวังสูง แล้วผู้เล่นยื่นสมัครสาขาศิลปะ ดนตรี การแสดง นิเทศฯ หรือปรัชญา จะเด้งการ์ดครอบครัวคัดค้าน (เลือก *เกลี้ยกล่อมโชว์ผลงาน* / *ดื้อเรียนเองด้วยเงินกู้ กยศ.+พาร์ตไทม์* / *ยอมเปลี่ยนไปเรียนสาขาที่พ่อแม่เลือก*)

5. **เรียนพิเศษ/ติวเข้มก่อนสอบ `[อัปเดต · 3.3.2]`:** ใช้ระบบของสเปก `05` §4 เป็นแหล่งเดียว (ช่องตาราง `self_dev` + ค่าคอร์ส) ไม่เขียนซ้ำที่นี่
6. **ทางเลือกหลังเข้าเรียน `[อัปเดต · 3.3.2]`:** ซิ่ว/สอบใหม่ · ย้ายสาขา · โอนย้ายสถาบัน · ลาออกกลางคัน · เรียนไม่จบ (รีไทร์ มีแจ้งเตือนล่วงหน้าและทางแก้) · เรียนควบงาน (ค่ำ/ออนไลน์) และ **ทุน 7 ชนิด** (เรียนดีเด่น, ความสามารถพิเศษ, ผู้ขาดแคลน, ครูใช้ทุน, มูลนิธิ/ญาติ, แลกเปลี่ยน, ทุนรัฐสายความมั่นคง) รายละเอียด/เงื่อนไข/ผลอยู่ใน `institutions.md` ส่วน "กติกาทางเลือกการเรียน" ทุกข้อเป็นเหตุการณ์ตัวเลือก >= 4 + ตัวเลือกพิเศษ ตาม CORE §6.1 และรักษาเกรดตาม `scholarshipMinGpa` ของข้อ 2.2
- อ้างอิง: CORE §6.1 · BACKLOG A · SCHEMAS §4.1

## 5. เควสเนื้อเรื่องต่อเนื่อง "รับน้องมหาวิทยาลัย" แบบแตกแขนง (`Freshman Branching Quest`) `[อัปเดต · 3.3.2]`
สร้างตามแม่พิมพ์ใน `docs/CORE_BLUEPRINTS.md` (§2 และ §3) เป็น **เควสระดับ Q-M** ตาม CORE §8 (3 ตอน, 3 Act, >= 3 สาย, >= 3 ฉากจบ, >= 1 ฉายา, lane `โรงเรียน-สังคม` ซ้อนกับเควสเลนเดียวกันไม่ได้) ทำงานใน **4 สัปดาห์แรกของปี 1** **เฉพาะสถาบันที่คอลัมน์ `รับน้อง` ใน `catalogs/institutions.md` ระบุว่ามี** (ภาคปกติ ไม่ใช่ภาคค่ำ/ออนไลน์/ต่างประเทศบางแห่ง) `[อัปเดต · 3.3.2]` ทุกตัวเลือกระบุ 5 ช่องผลตาม CORE §6.1 ล็อกผู้เยาว์/ทุกวัยไว้ที่ดราม่าสังคม/อำนาจ ไม่ลงความรุนแรง ยิงตอนย่อยห่างกันตอนละ 10 วันผ่าน `src/engine/quest.ts`:

- **Act 1 (สัปดาห์ที่ 1 — วันปฐมนิเทศและแยกสาย `branchRoute`):**
  - *ตัวเลือกที่ 1 (`route = 'spotlight'`):* ก้าวออกมารับไมค์อาสาเป็นตัวแทนรุ่นและช่วยงานสโมสรนักศึกษา
  - *ตัวเลือกที่ 2 (`route = 'social_chill'`):* ชวนกลุ่มเพื่อนข้างๆ แอบเฟดตัวไปนั่งร้านกาแฟทำความรู้จักกันแบบชิลล์ๆ
  - *ตัวเลือกที่ 3 (`route = 'rebel'`):* ปฏิเสธการเข้าแถวรับน้องแบบโซตัสอย่างเปิดเผย แล้วแยกตัวไปห้องสมุด/ชมรมอิสระ
- **Act 2 (สัปดาห์ที่ 2–3 — เหตุการณ์เฉพาะสายและจุดวัดทักษะ 3–4 ตัวเลือก):**
  - **หากอยู่สาย `spotlight`:** เจอเหตุการณ์ *"รุ่นพี่ทาบทามลงประกวดดาว-เดือนคณะ และศึกชิงตำแหน่งหัวหน้าโปรเจกต์รุ่น"* (ตรวจค่า `charisma`, `social`, หรือทักษะการแสดง/ดนตรี)
  - **หากอยู่สาย `social_chill`:** เจอเหตุการณ์ *"แก๊งเพื่อนใหม่ชวนตั้งวงดนตรี/ทำเพจลับ หรือชวนโดดกิจกรรมไปออกทริปต่างจังหวัด"* (ตรวจทักษะงานอดิเรกและการบริหารเวลาเรียน)
  - **หากอยู่สาย `rebel`:** เจอเหตุการณ์ *"รุ่นพี่สายว้ากไม่พอใจ เรียกคุยตัวต่อตัวหลังตึกคณะ"* (เลือกโต้กลับด้วยหลักการและกฎมหาวิทยาลัย `academic`/`social`, ประนีประนอม, หรือเปิดศึกดราม่าเต็มตัว)
- **Act 3 (สัปดาห์ที่ 4 — วันงานเฟรชชี่ไนท์ บทสรุปและมอบฉายา `CharacterTitle`):**
  - ตัดสินฉากจบจาก `branchRoute` + คะแนนสะสมใน `questVars` พร้อมเด้ง Toast มอบฉายาติดตัวละคร (`character.titles`):

### 6.1 ชีวิตในรั้ว: แนวประพฤติ ชื่อเสียงในรั้ว ตำนาน ชมรม สภานักเรียน เทศกาล `[ใหม่ · 3.3.2]`
> รายการ/ตัวเลขเต็มอยู่ใน `catalogs/activities.md` และ `catalogs/quests.md` กฎกลาง CORE §8

- **แนวประพฤติ (`CampusStance`):** เลือกได้ **ทุกเทอม** (ม.ต้นขึ้นไป) เช่น เงียบ/โลกส่วนตัวสูง, สายกิจกรรม, social butterfly, popular, เป็นหน้าเป็นตาโรงเรียน, เนิร์ด, ตัวแรงคุมถิ่น, ทั่วไป, นักกีฬา, วิชาการ (12 แนวใน catalog) **แนวที่เลือกกำหนดชุดเหตุการณ์/เควสที่เจอ** ไม่ใช่ XP
- **ชื่อเสียงในรั้ว (`Reputation`):** ค่าที่ "คนอื่นมองเรา" สะสมจากการกระทำจริง ไม่ใช่แค่แนวที่เลือก (ความนิยม, ความเกรงใจ, ภาพนักเรียนดี, ภาพนักกีฬา)
- **ตำนาน:** ภาพจำที่ติดตัวแปลงเป็นฉายา scope โรงเรียน (เก็บใน catalog ฉายา) ผลได้ทั้งดีและร้าย เช่น สายกิจกรรมที่ทำเควสจบดีอาจเจอแมวมอง (ผูก 3.5) / ตัวแรงคุมถิ่นอาจได้ลูกน้องหรือโดนครูเรียกพบ (เควส Q-C "ตำนานคุมถิ่น")
- **ชมรม:** เลือกเข้าได้ตั้งแต่ ม.ต้น/มหาวิทยาลัย บันไดตำแหน่ง สมาชิก -> รองประธาน -> ประธาน -> ที่ปรึกษา/ศิษย์เก่า ให้ทักษะ เพื่อน และเควสของชมรม
- **สภานักเรียน:** สมาชิก -> รองประธาน -> ชิงประธาน (เริ่มได้ **ม.5** เงื่อนไข: เคยอยู่สภา/ชมรม, เกรด, ชื่อเสียง, ครูรับรอง) เควสหาเสียง (Q-M) ผลชนะ/แพ้/สูสี ส่งผลโบนัสพอร์ต TCAS (นับใน "น้ำหนักฉายา/สภา/ชมรม" ข้อ 4.1)
- **กิจกรรมเทศกาล:** กีฬาสี (เชียร์ลีดเดอร์ ดรัมเมเยอร์ ถือป้าย นักกีฬา), ไหว้ครู, ดาว-เดือน, ค่ายอาสา, รับน้อง ผูกปฏิทินสเปก 06 §3
- **ล็อกผู้เยาว์:** ระดับดราม่าสังคม/นินทา/อำนาจ ไม่ลงความรุนแรง · อายุตามสเปก 03 §1
- อ้างอิง: CORE §8 · BACKLOG H · SCHEMAS §4 (CampusStance/Reputation, Club, Election)

## 7. งานความสามารถของเด็ก (`Talent Gigs`) `[ใหม่ · 3.3.3]`
> เปิดโอกาสให้เด็กกำพร้า/ฐานะไม่ดีมีทางหาเงินเก็บตั้งแต่เด็กจากความสามารถ (ไม่ใช่แรงงาน) **กติกาอายุ เพดานรายได้ และข้อห้าม อยู่ที่สเปก `03` §1 และ §1.1 แหล่งเดียว ไม่เขียนซ้ำที่นี่**

- **ต่ำกว่า 13 ปี:** ค้นพบและเรียนทักษะได้ ยังไม่มีรายได้ · **13–14 ปี:** ได้เฉพาะงานความสามารถ มีผู้ปกครองดูแล เย็น/วันหยุด มีเพดาน · **15–17 ปี:** ทำเองได้รวมขายของออนไลน์ ยังห้ามโอที/กะดึก/สถานบันเทิง/พนัน · **ก่อน 15:** ห้ามแรงงานทุกกรณี
- **รายการกิจกรรม** (รายการเต็ม `catalogs/activities.md` §5 รหัส `gig_*`): เปิดหมวกร้องเพลง (`gig_busking`) · แข่งเต้นงานตลาด/วัด (`gig_market_dance`) · ประกวดวาด/ร้องเพลงเยาวชน · รับวาดภาพออนไลน์ · ขายงานฝีมือ/ขนม · ขายของกับผู้ปกครอง · ติวหนังสือเด็กเล็ก · ช่วยร้านครอบครัว · ถ่ายภาพงานชุมชน · ทำคลิป/ไลฟ์เล็กๆ (15+)
- **ทักษะขั้นต่ำ:** ต้องมีทักษะตรงสายถึงขั้นต่ำของกิจกรรม (ตาม `catalogs/activities.md` §5; เกณฑ์ตัวเลขเป็น `[ยืนยัน]`)

```markdown
## 2. ระบบเลเวลทักษะ 1–5 และขั้นฝึก 3 ขั้น (`Skill Level & Training Tier`) `[อัปเดต · 3.3.1-FIX]` `[ยืนยัน]`
> แทนระบบเลเวล 0–100 ที่ขึ้นเร็วเกินไป (เดิมขึ้นได้ 3 แต้ม/สัปดาห์ และโรงเรียนปลดล็อกขั้นสนามจริงให้ academic อัตโนมัติ) ทุกทักษะ (`CoreSkillId` 6 ด้าน และ `DiscoveredSkillId` 7 ด้าน) ใช้ระบบเดียวกัน **ไม่มีเพดานตามวัยแยกต่างหาก** อายุถูกควบคุมผ่านเงื่อนไขของแต่ละขั้นฝึก

### 2.1 เลเวลและ XP
- ทักษะมี **Lv.1–Lv.5** แต่ละเลเวลมีแถบ XP ย่อย XP ที่ต้องใช้เพื่อเลื่อนไปเลเวลถัดไป:

| เลเวล | ชื่อเรียก | XP เพื่อเลื่อนขึ้น | ค่าคำนวณภายใน (0–100) |
| :-: | :-- | :-: | :-: |
| Lv.1 | เพิ่งเริ่ม | 100 | 0–19 |
| Lv.2 | พอทำได้ | 300 | 20–39 |
| Lv.3 | คล่อง | 700 | 40–59 |
| Lv.4 | ชำนาญ | 1,500 | 60–79 |
| Lv.5 | เชี่ยวชาญ | เต็มแล้ว | 90 (คงที่) |

- **ค่าคำนวณภายใน (0–100)** ใช้เป็นตัวเลขที่เงื่อนไขอื่นอ้างถึง (เช่น `academic >= 25` ในสายการเรียน) สูตร: `score = 20 × (Lv − 1) + floor(19 × สัดส่วนแถบ XP ปัจจุบัน)` สำหรับ Lv.1–4 และ Lv.5 = 90 UI แสดง Lv + แถบ XP ไม่ต้องโชว์ค่า 0–100
- **XP ต่อชั่วโมงฝึกพื้นฐาน** (ก่อนตัวคูณ): ฝึกเอง 0.25 · ลงคอร์ส 0.35 · สนามจริง 0.50 ที่ฝึก ~10 ชม./สัปดาห์ ได้ ~2.5 / ~3.5 / ~5 XP ต่อสัปดาห์
- **เพดานต่อสัปดาห์:** ไม่เกิน 6 XP ต่อทักษะ และไม่เกิน 10 XP รวมทุกทักษะ (กันฝึกรวดเดียว) ตัวคูณลดหลั่นภายในเลเวล: เริ่มเลเวล 1.00 ลดเป็น 0.85 ที่ปลายแถบ
- **เป้าหมายเวลา** (ฝึกจริงจัง ~10 ชม./สัปดาห์ ผู้ไม่มีพรสวรรค์): Lv.1→2 ≈ 1 ปี · Lv.2→3 ≈ 1.7 ปี · Lv.3→4 ≈ 3.8 ปี · Lv.4→5 ≈ 5.8 ปี (รวม ≈ 10+ ปี) ให้ปรับค่าฐานในข้อมูลโค้ดจนซิม 1000 ชีวิตได้ใกล้เป้า (±20%) พรสวรรค์ใหญ่ทำให้เร็วขึ้นไม่เกิน +30% (ดู §3) ไม่ข้ามขั้น
- **ย้ายเซฟเก่า (migration):** ค่าเก่า `s` (0–100) แปลงเป็น `Lv = min(4, floor(s/20)+1)` และ `s >= 80` เป็น Lv.5 โดยแถบ XP = สัดส่วน `(s mod 20)/20` ของแถบเลเวลนั้น ขั้นฝึกที่ปลดล็อก: `s >= 40` ถือว่าปลดล็อกขั้นคอร์ส `s >= 80` ถือว่าปลดล็อกขั้นสนามจริง

### 2.2 ขั้นฝึก 3 ขั้น (เพดานเก็บถาวรต่อทักษะ ห้ามตกกลับ)

| ขั้นฝึก | เงื่อนไข | ขึ้นได้ถึง | หมายเหตุ |
| :-- | :-- | :-: | :-- |
| **ฝึกเอง** | อายุ 6 ปีขึ้นไป ฝึกฟรีผ่านกิจกรรมหมวดพัฒนาตัวเอง/งานอดิเรก หรือเรียนในโรงเรียน | **Lv.2** | แถบ Lv.2 เติมเต็มได้แต่เลื่อนเป็น Lv.3 ไม่ได้จนกว่าจะปลดล็อกขั้นคอร์ส (แสดงสถานะ "รอปลดล็อกคอร์ส") |
| **ลงคอร์ส** | ผ่านคอร์สเรียนเสริม (ด้านล่าง) หรือเรียนตรงสายการเรียน/ชมรมที่ตรงทักษะ | **Lv.4** | อายุ 15 ขึ้นไปลงคอร์สเองได้ เด็กอายุน้อยกว่าเรียนผ่านเหตุการณ์ (เช่น `ev_child_music_class`) ได้ถึง **Lv.3** XP ที่ค้างในแถบนับต่อทันทีเมื่อปลดล็อก |
| **สนามจริง** | ต้องใช้จริง: ทำงานสายอาชีพที่ใช้ทักษะนั้น / เรียนมหาวิทยาลัยสายตรง / ลงแข่งขันหรือโปรเจกต์ระดับสูง (`competition_advanced`) **การเรียนในโรงเรียนไม่นับ** | **Lv.5** | ทักษะสายสังคม/สุขภาพ/ศิลปะใช้ประกวดหรือกิจกรรมระดับสูงแทนงานประจำได้ (กันทางตัน) |

- เพดานที่ปลดล็อกแล้วเก็บเป็นสถานะถาวรต่อทักษะ (`unlockedTier`) **ห้ามผูกกับ "คอร์สที่กำลังเรียน"** การลงคอร์สหลายทักษะสลับกันต้องไม่ทำให้เพดานของทักษะอื่นตกกลับ และ UI ต้องแสดงว่าเพดานปัจจุบันมาจากอะไร และจะปลดล็อกต่อได้อย่างไร

### 2.3 คอร์สเรียนเสริม (มีแบบเดียว)

- **ยกเลิก** ตัวเลือก 4 / 12 สัปดาห์เดิม คอร์สที่กำลังเรียนอยู่ในเซฟเก่าให้ใช้ต่อจนจบตามจำนวนสัปดาห์ที่เหลือ
```

```markdown
- **ช่องใช้งาน 3 ช่อง** (`activeMax = 3`): พรสวรรค์ที่เปิดเผยแล้วและอยู่ในช่องเท่านั้นที่ให้ผล ส่วนที่เกินช่อง (ตอนเกิดหรือค้นพบเพิ่ม) ไปอยู่ใน **lot** (`vaultMax = 5`) อัตโนมัติ พรสวรรค์ "อัจฉริยะ" กิน 1 ช่อง ผลรวมทั้งหมดผ่านเพดานกลาง +40% (CORE §9–10)
- **พรสวรรค์ใหม่ค้นพบระหว่างชีวิตได้** (เปิดเผยพรสวรรค์ที่ซ่อนอยู่ / ได้จากเหตุการณ์ใหญ่หายาก) แต่ **ห่างกันอย่างน้อย 3 ปีเกม** และไม่เกิน 1 ครั้งต่อช่วงชีวิต (เด็ก / ม.ต้น / ม.ปลาย / มหาวิทยาลัย / ทำงาน) ไม่ค้นพบติด ๆ กัน (กาชา 3.3.3 ไม่ติดเงื่อนไข 3 ปี แต่ติด lot ≤ 5)
- **สลับ** พรสวรรค์ช่องใช้งาน ↔ lot ได้เฉพาะ **จุดเปลี่ยน**: ขึ้นปีใหม่ (1 ม.ค.), เปิดเทอม (พ.ค. และ พ.ย.), ย้ายงาน/เปลี่ยนระดับการศึกษา, หรือหลังเหตุการณ์ T3 จุดเปลี่ยนชีวิต สลับได้ 1 ครั้งต่อจุดเปลี่ยน พรสวรรค์ใน lot ไม่ให้ผล แต่ความคืบหน้า (เช่น เกณฑ์ลางบอก) ไม่หาย
- **ข้อจำกัด (debuff)** แสดงในหน้าเดียวกันแต่ **ไม่กินช่อง** สลับออกไม่ได้ ต้อง "แก้" ตามช่องทางใน `catalogs/talents.md`
- **หน้า UI "ช่องพรสวรรค์"** (แท็บชีวิต): ช่องใช้งาน 3 ช่อง, lot, ปุ่มสลับ (เปิดเฉพาะเมื่อถึงจุดเปลี่ยน มิฉะนั้นแสดงเหตุผล), รายการข้อจำกัดพร้อมทางแก้ แสดงเฉพาะพรสวรรค์ที่เปิดเผยแล้ว
- ชนิดเพิ่มเติมที่ผู้ใช้ต้องการ: เสน่ห์ (`tal_charm` มีแล้ว), รูปหน้าฟ้าประทาน (`tal_face_blessed` เพิ่มใน `talents.md`)
- อ้างอิง: CORE §10 · BACKLOG A · SCHEMAS §4
```

### B4. หัวข้อ `### 2.2 ประเภทโรงเรียน (SchoolTier), เกรดเฉลี่ย (GPA) และ รด.` — ทำ 3 อย่าง
(1) ในข้อ `**ประเภทโรงเรียน:**` ตัดประโยคท้ายที่ว่าผู้เล่นกดขอย้ายโรงเรียน/สายได้ตรง ๆ แล้วใส่แทนด้วย `การย้ายโรงเรียนและย้ายสายทำผ่านเหตุการณ์ตามข้อ 2.1.1`
(2) แทนที่ข้อ `**การคำนวณ GPA (0.00–4.00):**` ทั้งก้อน (รวมข้อย่อยติด ร./ทุนที่อยู่ใต้ข้อนี้ให้คงไว้) ด้วย:

```markdown
- **การคำนวณ GPA (`0.00–4.00`) `[อัปเดต · 3.3.1-FIX]` `[ยืนยัน]`:** คำนวณทุกสิ้นเทอม (ต.ค. และ มี.ค.) และเก็บ **ประวัติเกรดรายเทอม** (แสดงใน UI) สูตร:
  `GPA_term = clamp(0, 4, 2.40 + 0.015×academic_score + studyBonus + talentBonus + teacherBonus − stressPenalty − energyPenalty − readinessPenalty + schoolMod + noise)`
  - `academic_score`: ค่าคำนวณ 0–100 ของทักษะ `academic` (สายอาชีพใช้ทักษะสาขาแทนครึ่งหนึ่ง)
  - `studyBonus = clamp(−0.40, +0.40, 0.04 × (ชั่วโมงเรียน+ทบทวน+ติวเฉลี่ยต่อสัปดาห์ − 5))`
  - `talentBonus`: พรสวรรค์ที่ใช้งานอยู่ (`tal_academic` / `tal_memory` / `tal_genius`) +0.10 / +0.20 / +0.30 ตามความแรง (รวมไม่เกิน +0.30)
  - `teacherBonus`: เหตุการณ์ครูชม/ตำหนิในเทอมนั้น −0.30 ถึง +0.30 (ครูชมต้องมีผลจริง ไม่ใช่แค่ข้อความ)
  - `stressPenalty = 0.40 × max(0, (Stress − 60)/40)` · `energyPenalty = 0.30 × max(0, (40 − พลังงานเฉลี่ย)/40)`
  - `readinessPenalty`: ตามข้อ 2.1.1 · `schoolMod`: วัด −0.05 / รัฐ 0 / เอกชน +0.05 / นานาชาติ +0.05
  - `noise`: สุ่มจาก seed −0.15 ถึง +0.15
  - เป้าหมายสมดุล (ซิม 1000 ชีวิต): ค่าเฉลี่ย ~2.9 (±0.5) ผู้ที่ทักษะวิชาการสูง+ตั้งใจเรียนได้ 3.4 ขึ้นไป ผู้ที่ทักษะต่ำ+ไม่ตั้งใจ ต่ำกว่า 2.2
  - หากสิ้นปี `GPA < 1.50` จะเกิดเหตุการณ์ **ติด ร. / มส.** ต้องเสียเวลาช่วงปิดเทอมซ่อมเกรด
  - หากได้รับทุนการศึกษา (`scholarshipMinGpa: 3.00`) แล้วสิ้นปีเกรดต่ำกว่าเกณฑ์ จะถูกตัดสิทธิ์ทุนทันที
```

(3) แทนที่ข้อ `**เรียน รด. (นักศึกษาวิชาทหาร):**` ทั้งข้อ ด้วย:

```markdown

  - **ผู้ชาย:** คัดเลือกผ่านเมื่อสุขภาพพื้นฐานผ่าน เมื่อจบ ม.6 ได้ `completedRotc = true` และสิทธิ์ยกเว้นเกณฑ์ทหารตอนอายุ 21 ปี (ใช้ใน Phase 7) `draftExemption = true`

  - อ้างอิง: CORE §6.1 · BACKLOG A · SCHEMAS §4
```

## 2. กฎเศรษฐกิจที่อยู่อาศัยที่ทำงานอยู่ใน Engine ปัจจุบัน
1. **กฎคุ้มครองผู้เยาว์ (`isMinor`):**
   - อายุ `< 15` ปี: **ไม่มีรายจ่ายครองชีพ** (ค่าเช่า ค่าอาหาร บิลรายเดือนเป็น `0 ฿`) **แต่ใช้เงินติดตัวซื้อขนม/อุปกรณ์/คอร์สได้** `[อัปเดต · 3.3.3]` (เงินติดตัวมาจากค่าขนม §4 และงานความสามารถตามสเปก 03 §1.1) ตัวเลขอายุทั้งหมดอ้างสเปก 03 §1 ไม่เขียนซ้ำ
   - อายุ `< 18` ปี ที่อาศัยกับผู้ปกครอง: ไม่ถูกหักค่าเช่าและค่าอาหารรายเดือน
2. **การตัดรอบบิลรายเดือน (`processMonthlyBills` ใน `economy.ts`):**
   - หักค่าเช่า/ค่าครองชีพทุกวันที่ 1 ของเดือน (แสดงวันตัดรอบในปฏิทินรายปี `LifePlannerPanel.tsx`)
   - หากเงินสดไม่พอจ่ายค่าเช่า จะถูกเปลี่ยนเป็นยอดหนี้ค้างชำระและเพิ่มความเครียด (`Stress`)

## 4. ค่าขนมและเงินติดตัวเด็ก `[ใหม่ · 3.3.3]` `[ยืนยัน ตัวเลข]`
> เงินติดตัว (`pocketMoney`) แยกจากเงินครอบครัวและเงินเก็บ ใช้ซื้อขนม อุปกรณ์ คอร์ส กาชาเพดานต่ำ (สเปก 03 §4) ไม่มีรายจ่ายครองชีพ

1. **ปุ่ม "ขอค่าขนม":** เปิดตั้งแต่อายุ 5 ขวบ จำนวนเริ่มที่ **5 ฿** เพิ่มตามอายุและฐานะครอบครัว (ประถมต้น 5–20 / ประถมปลาย 20–50 / ม.ต้น 50–150 / ม.ปลาย 100–300 ฿ ต่อครั้ง คูณตัวคูณฐานะ ยากจน 0.5 – ปานกลาง 1.0 – มั่งคั่ง 2.0) มีคูลดาวน์ (7 วัน)
2. **โอกาสสำเร็จ** ดูจาก: ความสัมพันธ์กับผู้ปกครอง, ฐานะ, หนี้ครอบครัว, นิสัยพ่อแม่/ผู้ปกครอง (เจ้าระเบียบ/ใจดี/ขี้เหนียว) ผลมีหลายแบบ ไม่ใช่ได้-ไม่ได้ (ได้เต็ม / ได้ลด / ได้พร้อมเงื่อนไข เช่น ช่วยงานบ้าน / ไม่ได้)
3. **ขอบ่อยเกินคูลดาวน์** กระทบความสัมพันธ์ (ลดลง) · **ครอบครัวยากจน** ขอแล้วอาจเกิดความรู้สึกผิดและความเครียดเล็กน้อย (เหตุการณ์ตัวเลือก ≥ 4 ตาม CORE §6.1 เช่น ไม่ขออีก, ขอน้อยลง, หาทางหาเงินเอง ผูกงานความสามารถเมื่อถึงอายุ)
4. **เงินเทศกาล:** วันเกิด, ตรุษจีน, สงกรานต์, ปีใหม่, วันเด็ก (ผูกปฏิทินสเปก 06 §3) ผู้ใหญ่ให้เงินตามความสัมพันธ์และฐานะ ไม่ต้องขอ
5. **เหตุการณ์ครอบครัวให้เงินเอง (สุ่ม):** เงื่อนไข ความสัมพันธ์ถึงเกณฑ์ (>= 50) ไม่ยากจน หนี้ครอบครัวไม่สูง ผลคือเงินเล็กน้อย + ความสนิทเพิ่ม
6. **ช่องทางอื่นให้หลากหลาย:** ช่วยงานบ้านได้ค่าขนม (ผูกพรีเซ็ต `family_helper` สเปก 05), ผู้ปกครองรุ่นตายายให้น้อยแต่สม่ำเสมอ, ญาติให้ตามเทศกาล
7. **เด็กกำพร้า/ฐานะไม่ดี:** ไม่มีค่าขนมเป็นปุ่มปกติ ใช้ช่องทางผู้ดูแลทดแทน + งานความสามารถ (สเปก 03 §1.1) + ทุนมูลนิธิ (สเปก 07 §3) เพื่อให้ยังมีทางออมเงิน
8. อ้างอิง: CORE §6.1 / §9 · BACKLOG I · SCHEMAS §4
